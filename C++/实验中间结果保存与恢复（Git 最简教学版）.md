# 🧪 实验中间结果保存与恢复（Git 最简教学版）

## 🔧 准备工作

在实验项目文件夹中打开终端，执行一次：

```
git init
```

> ✅ 创建本地版本库，开始记录实验步骤。

---

## 📦 学生：每完成一步，就提交 commit 一次

每次实验有进展，立即保存（先添加到暂存区，再提交）：

```
git add .//放到暂存区
git commit -m "step1: 数据加载完成"//真正的提交
```

继续实验：

```
git add .
git commit -m "step2: 缺失值处理"
```

```
git add .
git commit -m "step3: 特征工程完成"
```

> ✅ **所有 commit 都是学生的“工作日志”**  
> ✅ 不必命名完美，只要自己能看懂即可  

---

## 🔁 学生：想回到某个中间状态继续修改？

在实验过程中，你可能想基于某个已完成的步骤继续修改（例如回到 `step2` 重新尝试）。

### ✅ 步骤1：查看提交历史，找到目标 commit 编号

```
git log --oneline//查看历史版本的commit编号
```

输出示例：

```
abc1234 (main) step3: 特征工程完成
def5678 step2: 缺失值处理
ghi9012 step1: 数据加载完成
```

### ✅ 步骤2：恢复到该步骤的文件内容

```
git restore --source=def5678 .  //恢复到对应的版本, 注意有一个'.'
```

> ✅ 将工作区文件恢复到 `step2` 的状态

### ✅ 步骤3：让暂存区与工作区保持同步

```
git add .
```

> 💡 作用：把恢复后的文件重新加入暂存区，确保后续提交内容正确

之后你可以继续修改，并提交新步骤：

```
# 继续做新实验
git add .
git commit -m "step4: 优化清洗方法"
```

> ✅ 这样就基于 `step2` 开启了新的实验路径。

---

## 🏷️ 实验结束后：**回顾并为关键步骤打标签**

完成全部实验后，回顾提交历史，选择关键节点打标签，便于老师检查。

### ✅ 为关键 commit 打标签

```
git tag 数据加载 mno7890
git tag 数据清洗 jkl3456
git tag 特征工程 ghi9012
git tag 最终模型 def5678
```

> ✅ 标签名建议使用**中文或清晰英文**，便于老师理解  
> ✅ 标签名不要有空格（可用 `-` 或 `_` 代替，如 `data-clean`）

### 🔍 查看已打标签（两种方式）

| 方法            | 命令                  | 说明                      |
| ------------- | ------------------- | ----------------------- |
| 只看标签列表        | `git tag`           | 快速查看所有已打标签              |
| 查看完整提交记录（含标签） | `git log --oneline` | 显示所有 commit，标签会标注在对应提交后 |

---

### 🗑️ 如何删除错误的标签？

如果标签打错了，可以删除后重新打。

```
git tag -d 错误的标签名
```

> ✅ 例如：
> ```
> git tag -d 数据清先
> git tag 数据清洗 jkl3456
> ```

> ⚠️ 删除标签**不会影响提交历史**，非常安全。

---

## 🔍 教师如何检查中间结果？

老师可以使用 `git restore` 恢复到任意标签对应的状态，查看当时的文件内容。

### ✅ 恢复到某个标签

```
git restore --source=数据清洗 .
```

> ✅ 所有文件将变为“数据清洗”完成时的样子

### ✅ 恢复到某个 commit（使用编号）

```
git restore --source=jkl3456 .
```

> ✅ 效果与上一条命令完全相同

> 💡 老师可通过 `git tag` 或 `git log --oneline` 查看可用的恢复点。

---

## ✅ 总结

> 📌 **保存一步**：  
> `git add .`  
> `git commit -m "描述"`  
>
> 📌 **恢复任意状态**：  
> `git log --oneline` 找编号  
> `git restore --source=编号 .`  
> `git add .`  
>
> 📌 **打标签**：  
> `git tag 标签名 提交号`  
>
> 📌 **恢复标签**：  
> `git restore --source=标签名 .`  
>
> 📌 **删标签**：  
> `git tag -d 标签名`

---

## ✅ 优点

- ✅ **学生自由记录**：每步 `commit`，不怕丢失
- ✅ **教师检查方便**：通过标签快速定位关键节点
- ✅ **恢复灵活**：可用 `commit 编号` 或 `标签名` 恢复
- ✅ **命令极少**：只用 `add`、`commit`、`tag`、`restore`、`log`
- ✅ **安全可逆**：所有操作不影响提交历史
