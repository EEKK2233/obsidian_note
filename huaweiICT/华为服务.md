# ATC（Ascend Tensor Compiler）
ATC（Ascend Tensor Compiler）是华为 CANN 软件栈中的**模型转换编译工具**，作用是把开源框架训练好的模型变成昇腾 AI 处理器可执行的 **.om 离线模型**。一句话流程：

**原始模型 (Caffe/ONNX/TF/MindSpore) → ATC → 离线 .om 模型 → 昇腾 AscendCL 接口加载推理**

---

### 1. 核心功能

- **Parser 解析**：读取开源框架的拓扑与权重，生成中间 IR Graph
    
- **图优化**：算子融合、常量折叠、内存复用、调度策略优选
    
- **权重重排**：按 Davinci 核内存对齐要求重新排布参数
    
- **AIPP 预处理**：可在模型内部固化色域转换、减均值、抠图等预处理，节省 CPU 预处理耗时
    
- **动态 Batch/分辨率**：通过参数配置让同一份 .om 支持运行时变 shape
    
- **单算子编译**：单独把自定义 JSON 描述的一个算子编成 .om，用于白盒验证
    

---

### 2. 典型命令（ONNX → .om 示例）

- `framework=5` 代表 ONNX；0 为 Caffe，3 为 TensorFlow
    
- `soc_version` 用 `npu-smi info` 查到的 Name 前加 Ascend
    
- 开启 AIPP 后需再配 `aipp.cfg` 文件，把色域/均值/缩放写进去
    

---

### 3. 输出结果

成功后会得到 `resnet50.om`；若加 `--dump_json=true` 还会生成 `.json` 描述文件，方便查看节点属性、shape、dtype 等信息

。

---

### 4. 与推理流程衔接

.om 文件传到板端或云侧 → AscendCL 的 `aclmdlLoadFromFile` / `aclmdlExecute` 完成加载与执行，整个推理阶段无需再依赖原始框架

。

---

### 5. 常见注意点

- **PyTorch 需先转 ONNX**：`torch.onnx.export` → 再跑 ATC
    
- **动态 shape 场景**：用 `--input_shape_range` 或 `--dynamic_batch_size` 一次性把范围写进模型，减少重复编译
    
- **量化/稀疏**：可在图优化阶段自动完成，也可通过 `--precision_mode` 强制 FP16/INT8 策略
    
- **版本匹配**：ATC 所属 CANN 版本要与驱动固件一致，否则编译出的 .om 无法加载
    

一句话总结：**ATC 就是昇腾平台的“模型编译器”，把训练好的模型离线编译成高效、可部署的 .om 文件，并内置图优化、预处理固化、动态 shape 等能力，是昇腾推理 pipeline 的必经环节。**

# 华为云 EI 自然语言处理
华为云 EI 自然语言处理（NLP）服务是一组开箱即用的云端 API，把分词、命名实体识别、关键词提取、文本相似度、情感分析、文本分类、文本摘要、语言生成、机器翻译等常用 NLP 能力封装成 RESTful 接口。开发者通过简单的 HTTPS 调用或官方 SDK（Java/Python/Go 等）即可在业务系统里快速集成这些能力，无需自己训练和维护模型.
### 1. 主要功能

- **基础服务**：中文/英文分词、多粒度分词、依存句法分析、命名实体识别（基础版 & 领域版）、句向量、实体链接、关键词抽取、事件抽取、成分句法分析
- **语义服务**：文本相似度（基础/高级）、情感分析、文本分类、文本摘要、语言生成
- **机器翻译**：支持多种语言互译，可嵌入网站、APP、办公系统
- **对话机器人配套**：与 CBS 对话机器人服务联动，提供意图理解、槽位抽取、智能问答等能力
### 2. 产品特点

- **即调即用**：纯在线 API，无需下载模型；单用户默认 QPS 20，部分接口可到 50
- **计费灵活**：按调用量“按需计费”或购买“折扣套餐包”，不调用不产生费用
- **语言与协议**：中文、英文为主，通过 HTTPS/JSON 或 SDK 访问；必须能访问公网，暂不支持离线
- **与 ModelArts 协同**：若需要自定义领域模型，可在 ModelArts 上自训模型再上线，EI NLP 负责通用场景
### 3. 典型应用场景

- 智能问答/对话机器人
- 电商评论情感分析与关键词提取
- 内容推荐、资讯分类
- 知识图谱实体链接、事件抽取
- 多语言翻译、跨语言搜索
### 4. 快速接入流程

1. 开通华为云账号 → 在服务列表搜索“自然语言处理”并开通。
2. 获取 AK/SK，配置 SDK 或直接通过 API Explorer 调试。
3. 参考“成长地图”文档，用 Postman/Java/Python 完成首次调用

一句话总结：华为云 EI NLP 把通用文本解析、语义理解与翻译能力以 API 形式打包，帮助开发者在零算法背景、零硬件投入的情况下，一小时内在生产环境落地 NLP 功能。
