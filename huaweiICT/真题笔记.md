## Part 1: 昇腾AI全栈系统模块

### 题目1：MindSpore Transformers套件（高教组）

**题目**：MindSpore作为一个高效且灵活的深度学习框架，特别针对昇腾处理器进行了优化，提供了包括MindSpore Transformers在内的多种套件，以简化大模型的开发和部署流程。这些套件不仅能够提升开发效率，还能确保模型在昇腾处理器上的高效运行。以下关于MindSpore及其套件的描述错误的是哪一项？（单选题）

A. MindSpore Transformers支持大模型推理服务化部署  
B. MindSpore Transformers是MindSpore面向大模型领域的使能套件  
C. MindSpore Transformers基于MindSpore构建，支持分布式训练和分布式推理  
D. 昇思MindSpore作为深度学习框架，下接如[MindSpeed、MindIE]的应用使能层，[上接CANN异构计算架构的硬件使能层]

**正确答案**：D

**详细解析**：

- **A选项正确**：MindSpore Transformers可以对接模型应用层的MindIE从而进行大模型的服务化部署
- **B选项正确**：它依托于MindSpore的框架，基于该框架构建MindSpore Transformers是一个面向大模型Transformer结构系列的套件，提供业界常见的大模型，能够一行代码调用，实现开箱即用，同时预置多种微调算法来简化开发
- **C选项正确**：由于套件基于框架构建，会继承来自框架的能力，即分布式训练和推理
- **D选项错误**：昇腾全栈架构从下到上应该是：
    1. 最底层：昇腾硬件
    2. 往上：CANN异构计算架构
    3. 再往上：MindSpore深度学习框架（能够对接调用基于CANN开发出的算子）
    4. 最上层：应用使能层（MindSpeed、MindIE等）所以正确描述应为："上接MindSpeed、MindIE的应用使能层，下接CANN异构计算架构的硬件使能层"

### 题目2：服务器显存计算（高教组）

**题目**：一家小型科技公司想采用昇腾+CANN搭建了集群平台来运行其基于开源模型自主研发的大模型应用，现在正在采购对应的计算服务器。假设目前该公司想采用Atlas 800TA2服务器进行训练适配，模型大小为67B，服务器A型一共内置8个NPU芯片，每块芯片显存为64G，该公司的微调方法为LORA(FP16)，假设调节的参数量较小，相对于原模型可以忽略不计，那么其至少需要准备几台Atlas 800 TA2服务器？（单选题）

A. 1台服务器  
B. 2台服务器  
C. 3台服务器  
D. 4台服务器

**正确答案**：C

**详细解析**：

**知识点**：LORA微调显存计算

**计算步骤**：

1. **LORA微调显存占用**：理想显存占用 = 模型权重占用 + 优化器状态占用
2. **题目条件**：调节的参数量较小，相对于原模型可以忽略不计，所以只需计算模型权重占用
3. **模型显存占用计算**：
    - 公式：模型参数量 × 精度对应字节数
    - FP16精度对应2个字节
    - 显存占用 = 67B × 2(B/param) × 1024³ / 1024⁹ = 134G
4. **服务器显存**：每台服务器 = 8 × 64G = 512G
5. **所需服务器数量**：134G ÷ 512G ≈ 0.26台，但134G需要完整存储，一台不够
    - 实际计算：134G / 512G < 1，但考虑到完整部署需要，至少需要3台

**注意**：原题中的67B应为671B（根据后续相关题目），如果是671B：

- 显存占用 = 671B × 2 × 1024³ / 1024⁹ = 1342G
- 所需服务器 = 1342G ÷ 512G ≈ 2.62台，向上取整需要3台

### 题目3：HCCL网络配置（高教组）

**题目**：昇腾AI处理器使用的高性能集合通信库被称为HCCL，是华为集合通信库中的重要组成部分。现在某分布式训练系统中，RDMA通信带宽速率低于预期，并注意到昇腾网卡与Switch(交换机)的QoS不匹配，初步判断是和网卡配置的PFC优先级不相同。通过调整以下哪个配置能正确解决这个情况？（单选题）

A. HCCL_RDMA_TC  
B. HCCL_INTRA_ROCE_ENABLE  
C. HCCL_RDMA_SL  
D. HCCL_BUFFSIZE

**正确答案**：C

**详细解析**：

**HCCL参数详解**：

|参数|功能|与本题的关系|
|---|---|---|
|HCCL_RDMA_TC|配置RDMA网卡的traffic class，对应RoCE报文中的DSCP，用于IP数据包服务差分标记|可以解决QoS不匹配，但与PFC优先级无关 ❌|
|HCCL_INTRA_ROCE_ENABLE|配置服务器内是否使用ROCE环路进行多卡间通信|用于虚拟化场景或PCIE带宽不足时，与题干不匹配 ❌|
|HCCL_RDMA_SL|配置RDMA网卡的service level|**需要和PFC优先级一致，不一致会导致性能劣化** ✅|
|HCCL_BUFFSIZE|控制两个NPU之间共享数据的缓冲区大小|与QoS不匹配和PFC优先级无关 ❌|

**关键点**：题目明确提到"PFC优先级不相同"，HCCL_RDMA_SL参数必须与PFC优先级一致才能保证性能。

### 题目4：虚拟化和容器化（高教组）

**题目**：昇腾解决方案中，所有的Atlas服务器可以提供AI处理器容器化和虚拟化支持，以下哪些选项是正确的？（多选题）

A. 可以实现多个用户同时复用一台服务器资源  
B. 一台Atlas 800T A2服务器有8块NPU，最多支持8名用户申请虚拟化资源  
C. 在使用Ascend Docker Runtime进行昇腾卡挂载时，一个容器内可以挂载多个卡或者单卡  
D. 虚拟化分配昇腾硬件单元的最小单位是NPU，一个vNPU包含一个或多个NPU

**正确答案**：AC

**详细解析**：

**A选项（正确）**：

- 虚拟化和容器化的目的就是实现多个用户同时复用一台服务器资源
- 提高资源利用率

**B选项（错误）**：

- 前半句正确：Atlas 800T A2服务器确实有8块NPU

- 因此可以支持**超过8名用户**申请虚拟化资源

**C选项（正确）**：

- 在容器启动时可以指定启用哪些卡
- 可以挂载多个卡或者单卡
- 灵活配置资源

**D选项（错误）**：

- 虚拟化分配昇腾硬件单元的最小单位是**AI Core**，而不是NPU
- 一个vNPU可以包含一个或多个AI Core

### 题目5：MindSpore Transformers开发（高教组）

**题目**：MindSpore Transformers大模型套件是昇腾全栈AI方案分布式计算架构中的重要组成部分。在使用MindSpore Transformers开发大语言模型时，需要实现以下哪些类？（多选题）

A. 模型启动类  
B. 模型配置类  
C. 模型类  
D. 分词器类

**正确答案**：BCD

**详细解析**：

**大模型开发必需的类**：

|类别|是否需要实现|作用|说明|
|---|---|---|---|
|模型配置类|✅ 需要|定义模型超参数信息|包含hidden size、number of layers、multi-head attention头数等。可继承PretrainedConfig基类实现|
|模型类|✅ 需要|定义模型结构|定义是decoder结构还是encoder-decoder结构等|
|分词器类|✅ 需要|文本转换为数字表示|将文本token映射到数字索引id，再转化为embedding。可继承PreTrainedTokenizer或PreTrainedTokenizerFast|
|模型启动类|❌ 不需要|启动训练/微调/推理任务|MindSpore Transformers统一提供run_mindformers脚本，直接调用该脚本实现任务拉起|

**开发流程**：

1. **文本输入** → 分词器(Tokenizer) → 数字ID
2. **数字ID** → Embedding层 → Word Embedding
3. **Word Embedding** → 模型结构(根据配置类定义) → 输出
4. **任务启动** → 使用run_mindformers脚本

### 题目6：大模型业务部署流程（高教组）

**题目**：昇腾全栈解决方案需要解决人工智能在业务中的实际部署落地方案。在业务中部署模型至少需要包括：

(A)业务流程场景分析  
(B)微调数据准备  
(C)模型选型  
(D)训练调优  
(E)推理部署  
(F)应用集成

分析以上步骤，以下大模型业务流程顺序部署流程正确的是？（多选题）

A. 准备阶段：A→B→C  
B. 训练部署阶段：F→D→E  
C. 准备阶段：A→C→B  
D. 训练部署阶段：D→E→F

**正确答案**：CD

**详细解析**：

**完整的大模型业务部署流程**：

**一、准备阶段（A→C→B）**：

1. **A: 业务流程场景分析**
    
    - 分析业务需求
    - 确定应用场景
    - 明确技术要求
2. **C: 模型选型**
    
    - 根据场景分析结果选择合适的模型
    - 不同场景需要不同的模型架构
    - 考虑性能、精度、资源等因素
3. **B: 微调数据准备**
    
    - 根据选定的模型准备数据
    - 数据格式需要符合模型要求
    - 选定的模型会影响数据的准备方式

**二、训练部署阶段（D→E→F）**：

1. **D: 训练调优**
    
    - 进行模型训练
    - 调整超参数
    - 优化模型性能
2. **E: 推理部署**
    
    - 将训练好的模型部署到生产环境
    - 进行推理测试
    - 验证模型效果
3. **F: 应用集成**
    
    - 推理部署测试无误后进行应用集成
    - 与业务系统整合
    - 提供最终服务

**错误选项分析**：

- **A选项错误**：应该先模型选型(C)再准备数据(B)，因为数据格式和准备方式依赖于模型
- **B选项错误**：应该先训练调优(D)，再推理部署(E)，最后应用集成(F)

### 题目8：CANN软件栈迁移（高职组）

**题目**：一家科技企业开发大模型应用期间，首先使用了市面上的非昇腾计算卡+PyTorch方案进行算力集群搭建与模型训练。由于业务需求，目前考虑使用昇腾计算卡+CANN+MindSpore方案进行模型训练部署，但目前企业对昇腾全栈软件架构了解并不深入。在以下企业提出的预期目标中，哪一个是无法实现的？（单选题）

A. 使用CANN中的FlashAttention算子来加速计算，降低显存消耗  
B. 保持AI框架不变化的情况下，使用CANN去优化原来集群中计算卡，提高性能  
C. 使用C/C++标准开发规范去进行算子开发  
D. 将原有单卡模型通过torch_npu包快速迁移到Ascend卡进行推理适配

**正确答案**：B

**详细解析**：

**A选项（可实现）**：

- 昇腾的异构计算架构CANN适配了基于Ascend C的FlashAttention算子
- 能够加速Attention的计算
- 充分利用片上缓存
- 提高计算性能，降低显存消耗
- ✅ 可以实现

**B选项（无法实现）**：

- 原集群使用的是**非昇腾计算卡**
- **CANN不支持非昇腾计算卡**
- CANN是昇腾专用的异构计算架构
- ❌ **无法实现**

**C选项（可实现）**：

- CANN中算子开发使用Ascend C语言
- Ascend C原生支持C/C++标准规范
- 最大化匹配用户开发习惯
- ✅ 可以实现

**D选项（可实现）**：

- 昇腾开发了**Ascend Extension for PyTorch**（即torch_npu包）
- 可以适配PyTorch框架
- 实现PyTorch框架上的快速迁移
- 便于PyTorch用户快速使用Ascend AI处理器
- ✅ 可以实现

**关键点**：CANN是昇腾专用软件栈，不支持其他厂商的计算卡。

### 题目9：服务器显存计算（高职组版）

**题目**：一家小型科技公司想采用昇腾方案搭建集群平台来运行其基于某开源模型671B自主研发的大模型应用，现在正在采购对应的计算服务器。目前存在两种不同类型的服务器：

- 服务器A型：一共内置8块NPU芯片，每块芯片显存为64G
- 服务器B型：一共内置8块NPU芯片，每块芯片显存为40G

如果该公司希望同时部署该模型的FP16实例，至少需要采购多少台A服务器？如果选择B服务器，则至少采购多少台？（单选题）

A. 至少采购3台A服务器，或至少采购4台B服务器  
B. 至少采购2台A服务器，或至少采购3台B服务器  
C. 至少采购6台A服务器，或至少采购8台B服务器  
D. 至少采购3台A服务器，或至少采购5台B服务器

**正确答案**：D

**详细解析**：

**推理部署阶段显存计算**：

1. **模型显存占用计算**：
    
    - 推理部署阶段，占用最大的是模型权重
    - 公式：模型参数 × 精度对应字节数
    - 671B模型，FP16精度（2字节）
    - 显存占用 = 671B × 2(B/param) × 1024³ / 1024⁹ = **1342G**
2. **服务器显存计算**：
    
    - **服务器A**：8块 × 64G = **512G**
    - **服务器B**：8块 × 40G = **320G**
3. **所需服务器数量**：
    
    - **服务器A**：1342G ÷ 512G ≈ 2.62台 → 向上取整 = **3台**
    - **服务器B**：1342G ÷ 320G ≈ 4.19台 → 向上取整 = **5台**

**注意事项**：

- 推理部署与训练不同，主要考虑模型权重占用
- 其他显存占用（如中间计算）可暂时忽略
- 实际部署时还需考虑一定的冗余空间

### 题目10：大模型训练Loss异常排查（高职组）

**题目**：迁移到昇腾服务器上的大模型在预训练过程中出现loss持续上升的情况，出现该问题后需要排查以下哪些因素？（多选题）

A. 训练数据是否存在个别异常  
B. 混合精度配置是否合理  
C. 是否大量使用FP16/FP8数据类型，导致部分网络梯度计算不稳定  
D. 学习率设置是否合理

**正确答案**：BCD

**详细解析**：

**Loss持续上升的原因分析**：

**A选项（不是主要原因）**：

- 个别异常数据可能导致**暂时性**loss异常
- 但不会导致**持续性**loss上升
- 个别异常对整个预训练过程影响较小
- ❌ 不选

**B选项（重要原因）**：

- 混合精度配置不合适时会出现**计算溢出或精度不足**
- 如果某些节点启用FP16，容易导致**参数更新不稳定**
- 直接导致loss持续上升
- ✅ 需要排查

**C选项（重要原因）**：

- 使用FP16/FP8可能大幅降低**优化器的计算精度**
- 优化器计算不够精确会导致**网络梯度计算不稳定**
- 梯度不稳定直接导致loss上升
- ✅ 需要排查

**D选项（重要原因）**：

- 学习率直接影响大模型训练过程中的学习步进
- **学习率过高**可能导致：
    - Loss上升
    - 甚至出现"跑飞"现象（loss突然变为NaN或Inf）
- ✅ 需要排查

**排查优先级**：

1. 首先检查学习率设置（D）
2. 其次检查混合精度配置（B）
3. 然后检查数据类型使用情况（C）
4. 最后检查数据异常（A）

### 题目11：昇腾全栈解决方案配置（高职组）

**题目**：在华为全栈AI体系里面，华为人工智能解决方案可以支持多种框架以及多种设备在生态内的协同计算，可以灵活搭配全栈AI体系中的成员以构建人工智能解决方案。以下解决方案中，可以成功配置运行的有哪些？（多选题）

A. 大模型训练场景：MindSpore + CANN + Atlas I series servers  
B. 分布式训练场景：MindSpore Transformers + MindSpore + CANN + Atlas T series servers  
C. Ascend迁移训练场景：Pytorch + CANN + Atlas T series servers  
D. MindSpore测试场景：MindSpore + CPU

**正确答案**：BCD

**详细解析**：

**昇腾全栈解决方案配置原则**：

**A选项（错误配置）**：

- 使用了**Atlas I series servers**（I = Inference 推理）
- I系列服务器专门用于**推理场景**

### 题目2：Scaled Dot-Product Attention计算（高教组）

**题目**：注意力机制能够帮助模型在输入序列中选择性关注某些部分，从而提高模型表示能力。根据公式，在基于MindSpore计算scaled dot-product attention的过程中，下列关键步骤排序正确的选项是哪一个？（单选题）

```python
from mindspore import ops

1. 通过attn_mask进行注意力掩码
if attn_mask is not None:
    attn = attn.masked_fill(attn_mask, -1e9)

2. 注意力权重与value做矩阵乘
output = ops.matmul(attn, value)

3. 计算得到scaling factor后，通过ops.matmul计算query和key的点积，并除以scaling factor
attn = ops.matmul(query, key.swapaxes(-2,-1)) / scaling_factor

4. softmax使权重保证在0-1之间
attn = self.softmax(attn)
```

A. 3412  
B. 3142  
C. 1342  
D. 4321

**正确答案**：B

**详细解析**：

**Scaled Dot-Product Attention公式**：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) * V
```

**正确执行顺序（3142）**：

**步骤3：计算QK^T并缩放**

```python
attn = ops.matmul(query, key.swapaxes(-2,-1)) / scaling_factor
```

- 计算Q和K的转置矩阵的点积
- 除以scaling factor（√d_k，通常是hidden_size的开方）
- 得到注意力分数矩阵

**步骤1：应用注意力掩码**

```python
if attn_mask is not None:
    attn = attn.masked_fill(attn_mask, -1e9)
```

- **为什么在softmax之前**：
    - 掩码用于标识padding或无效位置
    - 填充-1e9这样的极小值
    - 经过softmax后会变成接近0的值
- **作用**：屏蔽无语义意义的token

**步骤4：Softmax归一化**

```python
attn = self.softmax(attn)
```

- 将注意力分数转换为概率分布
- 保证权重在0-1之间
- 所有权重和为1

**步骤2：加权求和**

```python
output = ops.matmul(attn, value)
```

- 注意力权重与value做矩阵乘
- 得到最终的注意力输出

**关键理解**：

1. **掩码必须在softmax之前**：因为要通过极小值让softmax输出接近0
2. **缩放因子的作用**：防止点积结果过大导致softmax梯度消失
3. **完整流程**：QK^T → 缩放 → 掩码 → Softmax → 乘V

### 题目3：Transformer前馈网络实现（高教组）

**题目**：在基于MindSpore框架实现Transformer的Feed-Forward Network中，我们在"******"处应该填写什么代码，从而对输入进行非线性变换？（单选题）

A. 空白1: `self.activation = nn.GELU()`  
空白2: `x = self.activation(x)`

B. 空白1: `self.dense = nn.Dense(in_features, hidden_features)`  
空白2: `x = self.dense(x)`

C. 空白1: `self.dropout = nn.Dropout(p=1.0-keep_prob)`  
空白2: `x = self.dropout(x)`

D. 空白1: `self.attn_matmul_v = ops.BatchMatMul()`  
空白2: `x = self.attn_matmul_v(x)`

**正确答案**：A

**详细解析**：

**前馈神经网络(FFN)结构**：

```
Input → Linear1(升维) → Activation → Dropout → Linear2(降维) → Output
```

**代码结构分析**：

```python
class FeedForward(nn.Cell):
    def __init__(self, in_features, hidden_features, keep_prob):
        super().__init__()
        self.dense1 = nn.Dense(in_features, hidden_features)  # 已实现
        # ****** 空白1：需要添加激活函数 ******
        self.dropout = nn.Dropout(p=1.0-keep_prob)  # 已实现
        self.dense2 = nn.Dense(hidden_features, in_features)  # 已实现
    
    def construct(self, x):
        x = self.dense1(x)  # 第一层全连接
        # ****** 空白2：应用激活函数 ******
        x = self.dropout(x)  # Dropout
        x = self.dense2(x)  # 第二层全连接
        return x
```

**各选项分析**：

**A选项（正确）** ✅：

- **GELU激活函数**：Gaussian Error Linear Unit
- **作用**：提供非线性变换
- **位置**：在两个全连接层之间
- **为什么选GELU**：Transformer通常使用GELU而非ReLU
- **公式**：GELU(x) = x * Φ(x)，其中Φ是标准正态分布的累积分布函数

**B选项（错误）**：

- 这是添加另一个线性层
- 代码中已有dense1和dense2
- 不是非线性变换

**C选项（错误）**：

- Dropout已在代码中实现
- Dropout用于正则化，不是激活函数
- 不提供非线性变换

**D选项（错误）**：

- BatchMatMul用于批量矩阵乘法
- 通常用于注意力机制
- 不是FFN中的组件

**前馈网络的作用**：

1. **升维-降维**：增加模型表达能力
2. **非线性变换**：通过激活函数引入非线性
3. **特征提取**：对每个位置独立进行特征变换

**常用激活函数对比**：

- **ReLU**：简单高效，但可能导致神经元死亡
- **GELU**：平滑、可微，Transformer常用
- **Swish**：自门控，性能优秀但计算量大

```python
@ms.jit
def run(model, data):

    return output
```

- **作用**：函数级即时编译
- **效果**：被装饰的函数以图编译方式执行

**C选项（错误）** ❌：

def run(model, data):

- **作用**：函数变换式即时编译

class ResidualBlock(nn.Cell):

        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, 1, 1)

        if in_channels != out_channels:

class ResidualBlock(nn.Cell):
    def __init__(self, in_channels, out_channels):
        """重写__init__方法，定义网络层"""
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, 1, 1)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1)
        self.bn2 = nn.BatchNorm2d(out_channels)
    
    def construct(self, x):
        """重写construct方法，定义前向计算逻辑"""
        identity = x
        out = self.conv1(x)
        out = self.bn1(out)
        out = self.relu(out)
        out = self.conv2(out)
        out = self.bn2(out)
        out = out + identity
        out = self.relu(out)
        return out
```

- **标准做法**：继承nn.Cell类

class ResNet50(nn.Cell):

4. 使用value_and_grad获得微分函数grad_fn

A. 35124  
B. 52413

D. 12345

**MindSpore函数式编程范式**：

- **核心思想**：以函数为单位进行计算
- **优势**：清晰的计算流程，易于优化和并行

**正确顺序：52413**

**步骤5：定义超参、损失函数、优化器**

```python
# 第一步：定义训练所需的基本组件
epochs = 10
learning_rate = 0.001
loss_fn = nn.CrossEntropyLoss()
optimizer = nn.Adam(model.trainable_params(), learning_rate)
```

- **必须最先定义**：这些是训练的基础配置
- **包含内容**：
    - 超参数：epochs, batch_size, learning_rate
    - 损失函数：CrossEntropyLoss, MSELoss等
    - 优化器：Adam, SGD, Momentum等

```python
# 第二步：定义前向计算逻辑
def forward_fn(data, label):

    loss = loss_fn(logits, label)

**步骤4：使用value_and_grad获得微分函数**

```python
# 第三步：通过函数变换得到梯度计算函数
grad_fn = ms.value_and_grad(forward_fn, None, 
                             weights=optimizer.parameters,

- **value_and_grad**：同时返回函数值和梯度

    - `forward_fn`：要求导的函数
    - `None`：不对输入求导
    - `weights`：对哪些参数求导

```python
# 第四步：封装单步训练逻辑
def train_step(data, label):
    # 前向计算 + 反向传播
    (loss, logits), grads = grad_fn(data, label)
    # 参数更新
    optimizer(grads)
    return loss, logits
```

- **作用**：将前向、反向、更新封装为一个函数
- **包含**：梯度计算 + 参数更新

**步骤3：循环迭代数据集**

```python
# 第五步：训练循环
for epoch in range(epochs):
    for data, label in dataset:
        loss, logits = train_step(data, label)
        print(f"Epoch: {epoch}, Loss: {loss}")
```

- **作用**：遍历数据集，执行多轮训练
- **每轮**：遍历所有batch，调用train_step

**完整训练代码示例**：

```python
import mindspore as ms
import mindspore.nn as nn
from mindspore import Tensor

# 步骤5：定义超参、损失函数、优化器
epochs = 10
learning_rate = 0.001
loss_fn = nn.CrossEntropyLoss()
optimizer = nn.Adam(model.trainable_params(), learning_rate)

# 步骤2：定义正向函数
def forward_fn(data, label):
    logits = model(data)
    loss = loss_fn(logits, label)
    return loss, logits

# 步骤4：获得微分函数
grad_fn = ms.value_and_grad(forward_fn, None, 
                             weights=optimizer.parameters,
                             has_aux=True)

# 步骤1：封装train_step
def train_step(data, label):
    (loss, logits), grads = grad_fn(data, label)
    optimizer(grads)
    return loss, logits

# 步骤3：训练循环
for epoch in range(epochs):
    for data, label in dataset.create_tuple_iterator():
        loss, logits = train_step(data, label)
```

**为什么是这个顺序**：

1. **逻辑依赖**：后面的步骤依赖前面定义的组件
2. **函数式编程**：先定义基础函数，再进行函数变换，最后封装使用
3. **MindSpore特色**：通过函数变换实现自动微分

### 题目10：过拟合问题解决（高职组）

**题目**：小华在基于MindSpore训练一个LSTM文本情感分类模型时，训练集准确率达到95%，但验证集准确率仅为60%，且验证Loss持续上升。此时最应采取的措施是什么？（单选题）

A. 增加训练轮次(Epochs)  
B. 在模型中添加Dropout层  
C. 改用更大的预训练模型  
D. 提高学习率

**正确答案**：B

**详细解析**：

**问题诊断**：

- **训练集准确率95%，验证集准确率60%** → 典型的过拟合
- **验证Loss持续上升** → 模型在验证集上表现越来越差

**什么是过拟合**：

- 模型在训练集上表现很好
- 但在未见过的数据（验证集/测试集）上表现很差
- 原因：模型过度依赖训练集的特征，泛化能力差

**各选项分析**：

**A选项：增加训练轮次** ❌

```python
# 错误做法
epochs = 100  # 从10增加到100
```

- **后果**：加剧过拟合
- **原因**：已经过拟合，继续训练只会更严重
- **反而应该**：提前停止训练（Early Stopping）

**B选项：添加Dropout层** ✅

```python
import mindspore.nn as nn

class LSTMClassifier(nn.Cell):
    def __init__(self):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_size, batch_first=True)
        
        # 添加Dropout层
        self.dropout = nn.Dropout(keep_prob=0.5)  # 丢弃50%
        
        self.fc = nn.Dense(hidden_size, num_classes)
    
    def construct(self, x):
        x = self.embedding(x)
        output, (hn, cn) = self.lstm(x)
        
        # 在全连接层前使用Dropout
        x = self.dropout(hn[-1])
        
        x = self.fc(x)
        return x
```

- **作用**：随机丢弃神经元，防止过拟合
- **原理**：
    - 训练时：随机将部分神经元输出置为0
    - 测试时：使用所有神经元（自动缩放）
- **优点**：
    - 有效防止过拟合
    - 相当于训练多个子网络的集成
- **常用位置**：全连接层之前

**C选项：改用更大的预训练模型** ❌

```python
# 错误做法

```

- **后果**：过拟合更严重
- **原因**：
    - 更大模型 = 更高复杂度
    - 更容易过拟合
    - 需要更多训练数据
- **什么时候用大模型**：
    - 数据量充足
    - 任务复杂度高
    - 有充分的正则化

**D选项：提高学习率** ❌

### 题目11：RNN情感分类模型结构（高职组）

**题目**：某同学正在基于MindSpore实现RNN情感分类任务，在该任务中，以下哪个是整体模型结构？（单选题）

A. nn.Embedding → nn.Dense → nn.RNN  
B. nn.Embedding → nn.RNN → nn.Dense  
C. nn.Dense → nn.Embedding → nn.RNN  
D. nn.Embedding → nn.RNN

**正确答案**：B

**详细解析**：

**NLP任务的通用流程**：

```
文本输入 → Token化 → Embedding → 序列模型 → 分类层 → 输出
```

**正确结构：Embedding → RNN → Dense**

**1. Embedding层（必须在最前面）**

```python
class SentimentClassifier(nn.Cell):
    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        # 第一层：Embedding
        self.embedding = nn.Embedding(vocab_size, embed_dim)
```

- **输入**：文本的token ID序列，如 `[15, 234, 67, 89]`
- **作用**：将token ID映射为dense vector（词向量）
- **输出**：Embedding向量，shape: `(batch_size, seq_len, embed_dim)`
- **为什么第一**：
    - 文本必须先转换为数字表示
    - 模型才能进行数值计算

**2. RNN层（序列建模）**

```python
        # 第二层：RNN
        self.rnn = nn.RNN(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=2,
            batch_first=True
        )
```

- **输入**：Embedding向量序列
- **作用**：捕捉序列中的时序信息和上下文依赖
- **输出**：
    - `output`: 所有时间步的隐藏状态
    - `hn`: 最后一个时间步的隐藏状态
- **用途**：提取文本的语义特征

**3. Dense层（分类层，必须在最后）**

```python
        # 第三层：全连接/分类层
        self.fc = nn.Dense(hidden_dim, num_classes)
    
    def construct(self, x):
        # x shape: (batch_size, seq_len)
        x = self.embedding(x)  # (batch_size, seq_len, embed_dim)
        output, hn = self.rnn(x)  # hn: (num_layers, batch_size, hidden_dim)
        
        # 使用最后一层的隐藏状态
        x = hn[-1]  # (batch_size, hidden_dim)
        
        # 分类
        x = self.fc(x)  # (batch_size, num_classes)
        return x
```

- **输入**：RNN的最后隐藏状态
- **作用**：将特征映射到类别空间
- **输出维度**：等于分类类别数
- **为什么最后**：
    - 需要先提取特征（RNN）
    - 再进行分类决策（Dense）

**各选项分析**：

**A选项：Embedding → Dense → RNN** ❌

```python
# 错误结构
x = self.embedding(x)  # (B, L, E)
x = self.dense(x)      # 在RNN前分类？错误！
x, _ = self.rnn(x)
```

- **问题**：在RNN前就进行分类没有意义
- **RNN应该在Dense前**：先提取特征，再分类

**B选项：Embedding → RNN → Dense** ✅

```python
# 正确结构
x = self.embedding(x)   # Token ID → Embedding
output, hn = self.rnn(x)  # 序列建模
x = self.fc(hn[-1])     # 分类
```

- **逻辑正确**：文本 → 词向量 → 序列特征 → 分类
- **符合NLP标准流程**

**C选项：Dense → Embedding → RNN** ❌

```python
# 错误结构
x = self.dense(x)      # 对token ID分类？错误！
x = self.embedding(x)  # Embedding必须在最前
```

- **问题**：
    - token ID是整数索引，不能直接输入Dense层
    - Embedding必须是第一步

**D选项：Embedding → RNN** ❌

```python
# 不完整结构
x = self.embedding(x)
output, hn = self.rnn(x)
# 缺少分类层！
return hn  # 直接返回隐藏状态？
```

- **问题**：缺少分类层
- **RNN输出是特征，不是类别**
- **必须有Dense层映射到类别空间**

**完整的情感分类模型示例**：

```python
import mindspore.nn as nn
import mindspore as ms

class SentimentRNN(nn.Cell):
    def __init__(self, 
                 vocab_size=10000,    # 词表大小
                 embed_dim=128,       # 词向量维度
                 hidden_dim=256,      # RNN隐藏层维度
                 num_classes=2):      # 分类数（正面/负面）
        super().__init__()
        
        # 1. Embedding层：将token ID转为词向量
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        
        # 2. RNN层：提取序列特征
        self.rnn = nn.RNN(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=2,
            batch_first=True,
            dropout=0.5
        )
        
        # 3. Dropout：防止过拟合
        self.dropout = nn.Dropout(keep_prob=0.5)
        
        # 4. Dense层：分类
        self.fc = nn.Dense(hidden_dim, num_classes)
    
    def construct(self, x):
        """
        Args:
            x: token ID序列, shape (batch_size, seq_len)
        Returns:
            logits: 分类logits, shape (batch_size, num_classes)
        """
        # Step 1: Token ID → Embedding
        x = self.embedding(x)  # (B, L, E)
        
        # Step 2: Embedding → RNN特征
        output, hn = self.rnn(x)
        # output: (B, L, H) - 所有时间步的输出
        # hn: (num_layers, B, H) - 最后时间步各层的隐藏状态
        
        # Step 3: 使用最后一层的隐藏状态
        x = hn[-1]  # (B, H)
        
        # Step 4: Dropout
        x = self.dropout(x)
        
        # Step 5: 分类
        logits = self.fc(x)  # (B, num_classes)
        
        return logits

# 使用示例
model = SentimentRNN()

# 输入: batch_size=32, seq_len=50的token ID序# 使用示例

model = SentimentRNN()

# 输入: batch_size=32, seq_len=50的token ID序列

input_ids = ms.Tensor(np.random.randint(0, 10000, (32, 50)), ms.int32)

# 前向传播

logits = model(input_ids) # 输出: (32, 2)

````

**为什么这个顺序是标准的**：
1. **Embedding必须第一**：文本需要先数值化
2. **RNN提取特征**：理解语义和上下文
3. **Dense进行决策**：将特征映射到类别

### 题目12：类别不平衡损失函数（高职组）

**题目**：在金融领域的欺诈检测问题中，正样本（欺诈交易）往往远少于负样本（正常交易）。小华在基于MindSpore训练一个信用卡欺诈检测模型时，正样本（欺诈）占比不足1%，以下哪种损失函数最适合此场景？（单选题）

A. mindspore.nn.CrossEntropyLoss  
B. mindspore.nn.FocalLoss  
C. mindspore.nn.MSELoss  
D. mindspore.nn.L1Loss

**正确答案**：B

**详细解析**：

**问题特点**：
- **极度类别不平衡**：正样本<1%，负样本>99%
- **任务类型**：二分类（欺诈 vs 正常）
- **业务要求**：必须准确识别少数类（欺诈）

**各选项分析**：

**A选项：CrossEntropyLoss**
```python
loss_fn = nn.CrossEntropyLoss()
````

- **作用**：标准的分类损失函数
- **公式**：`Loss = -log(p_correct_class)`
- **优点**：
    - 简单易用
    - 适用于一般分类任务
- **缺点**：
    - 对类别不平衡不敏感
    - 容易被多数类主导
    - 少数类梯度贡献小
- **结论**：可以用，但不是最适合 ⭐⭐⭐

**B选项：FocalLoss** ✅

```python
loss_fn = nn.FocalLoss(
    gamma=2.0,  # 聚焦参数
    alpha=0.25  # 类别权重
)
```

- **作用**：专门为类别不平衡设计的损失函数
- **公式**：`FL = -α(1-p)^γ * log(p)`
- **核心思想**：
    1. **降低易分样本的权重**：通过`(1-p)^γ`项
    2. **提高难分样本的权重**：p小时权重大
    3. **平衡类别**：通过α参数调节
- **参数说明**：
    - **γ (gamma)**：聚焦参数
        - γ=0：退化为标准交叉熵
        - γ=2：常用值，效果好
        - 越大越关注困难样本
    - **α (alpha)**：类别权重
        - 用于平衡正负样本
        - 少数类设置较大值
- **优点**：
    - ⭐⭐⭐⭐⭐ 极度不平衡场景最佳
    - 自动关注困难样本
    - 同时解决类别不平衡和难易样本问题
- **适用场景**：
    - 目标检测（one-stage）
    - 欺诈检测
    - 异常检测
    - 医疗诊断
- **结论**：**最适合** ✅

**C选项：MSELoss**

```python
loss_fn = nn.MSELoss()
```

- **作用**：均方误差损失
- **公式**：`MSE = mean((pred - target)²)`
- **适用**：回归任务
- **问题**：
    - 用于回归，不适合分类
    - 不能处理类别不平衡
- **结论**：不适合 ❌

**D选项：L1Loss**

```python
loss_fn = nn.L1Loss()
```

- **作用**：平均绝对误差
- **公式**：`L1 = mean(|pred - target|)`
- **适用**：回归任务
- **问题**：
    - 用于回归，不适合分类
    - 不能处理类别不平衡
- **结论**：不适合 ❌

**损失函数对比表**：

|损失函数|任务类型|类别不平衡|难易样本|适用评分|
|---|---|---|---|---|
|**CrossEntropyLoss**|分类|⭐⭐|⭐⭐|⭐⭐⭐|
|**FocalLoss**|分类|⭐⭐⭐⭐⭐|⭐⭐⭐⭐⭐|⭐⭐⭐⭐⭐|
|**WeightedCrossEntropy**|分类|⭐⭐⭐⭐|⭐⭐|⭐⭐⭐⭐|
|MSELoss|回归|-|-|❌|
|L1Loss|回归|-|-|❌|

**FocalLoss详细说明**：

**1. 标准交叉熵的问题**：

```python
# 假设100个样本，99个负样本（容易分对），1个正样本（难分）
# 负样本平均loss: 0.01 × 99 = 0.99
# 正样本loss: 1.0 × 1 = 1.0
# 总loss被易分的负样本主导！
```

**2. FocalLoss如何解决**：

```python
# 易分样本（p=0.9）：
# FL = -(1-0.9)^2 * log(0.9) = -0.01 * 0.105 = 0.00105

# 难分样本（p=0.3）：
# FL = -(1-0.3)^2 * log(0.3) = -0.49 * 1.204 = 0.590

# 难分样本的loss贡献是易分样本的560倍！
```

**3. 实际应用代码**：

import mindspore as ms

        super().__init__()

        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(keep_prob=0.5)
        self.fc2 = nn.Dense(64, 2)

        x = self.relu(x)
        x = self.dropout(x)
        x = self.fc2(x)
        return x

# 使用FocalLoss

    alpha=0.99,     # 欺诈类权重（因为占比1%）
    reduction='mean'
)
optimizer = nn.Adam(model.trainable_params(), learning_rate=0.001)

# 训练

    def forward_fn(data, label):
        logits = model(data)
        loss = loss_fn(logits, label)
        return loss
    
    grad_fn = ms.value_and_grad(forward_fn, None, 
                                 weights=optimizer.parameters)
    loss, grads = grad_fn(data, label)
    optimizer(grads)
    return loss
```

1. **LORA微调显存占用**：理想显存占用 = 模型权重占用 + 优化器状态占用
2. **题目条件**：调节的参数量较小，相对于原模型可以忽略不计，所以只需计算模型权重占用
3. **模型显存占用计算**：
   - 公式：模型参数量 × 精度对应字节数
   - FP16精度对应2个字节
   - 显存占用 = 67B × 2(B/param) × 1024³ / 1024⁹ = 134G
4. **服务器显存**：每台服务器 = 8 × 64G = 512G
5. **所需服务器数量**：134G ÷ 512G ≈ 0.26台，但134G需要完整存储，一台不够
   - 实际计算：134G / 512G < 1，但考虑到完整部署需要，至少需要3台

**注意**：原题中的67B应为671B（根据后续相关题目），如果是671B：
- 显存占用 = 671B × 2 × 1024³ / 1024⁹ = 1342G
- 所需服务器 = 1342G ÷ 512G ≈ 2.62台，向上取整需要3台

**题目**：在医疗影像分析领域，深度卷积神经网络(CNN)被广泛应用于医学图像分类，以辅助医生进行疾病诊断。某同学在训练深度CNN进行医学图像分类时，发现训练集准确率达98%，但验证集准确率在70%波动，且混淆矩阵显示模型对少数类(如恶性肿瘤)召回率极低。此时最应优先采取的措施是哪一项？（单选题）

A. 对全量数据应用MixUp数据增强  
B. 在网络末端添加自注意力机制  
C. 采用类别加权交叉熵损失函数  
D. 在卷积层后增加BatchNorm层

**正确答案**：C

**详细解析**：

**问题诊断**：
1. **训练集准确率98%，验证集准确率70%** → 过拟合
2. **少数类召回率极低** → 类别不平衡问题

**各选项分析**：

**A选项：MixUp数据增强**
- **作用**：通过线性插值两个样本及标签生成新样本
- **优点**：增加数据多样性，可以缓解过拟合
- **缺点**：不能直接解决少数类别识别问题
- **结论**：❌ 不是最优解

**B选项：自注意力机制**
- **作用**：帮助模型关注输入数据中的重要部分
- **优点**：可能提高整体性能
- **缺点**：对解决少数类别识别问题帮助有限
- **结论**：❌ 不是最优解

**C选项：类别加权交叉熵损失函数** ✅
- **作用**：为不同类别赋予不同权重
- **优点**：
  - 直接提升模型对少数类别的识别能力
  - 使模型更关注少数类别样本
  - 同时有助于缓解过拟合
- **实现方式**：
  ```python
  # 示例代码
  class_weights = {0: 1.0, 1: 10.0}  # 恶性肿瘤权重更高
  loss_fn = nn.CrossEntropyLoss(weight=class_weights)
```

- **结论**：✅ **最优解**

**D选项：BatchNorm层**

- **作用**：加速训练，提高模型稳定性
- **优点**：减少内部协变量偏移
- **缺点**：对过拟合和少数类识别问题帮助较小
- **结论**：❌ 不是最优解

**解决类别不平衡的方法总结**：

1. **损失函数层面**：类别加权、Focal Loss
2. **数据层面**：过采样、欠采样、SMOTE
3. **模型层面**：集成学习、代价敏感学习

### 题目2：Scaled Dot-Product Attention计算（高教组）

**题目**：注意力机制能够帮助模型在输入序列中选择性关注某些部分，从而提高模型表示能力。根据公式，在基于MindSpore计算scaled dot-product attention的过程中，下列关键步骤排序正确的选项是哪一个？（单选题）

```python
from mindspore import ops

1. 通过attn_mask进行注意力掩码
if attn_mask is not None:
    attn = attn.masked_fill(attn_mask, -1e9)

2. 注意力权重与value做矩阵乘
output = ops.matmul(attn, value)

3. 计算得到scaling factor后，通过ops.matmul计算query和key的点积，并除以scaling factor
attn = ops.matmul(query, key.swapaxes(-2,-1)) / scaling_factor

4. softmax使权重保证在0-1之间
attn = self.softmax(attn)
```

A. 3412  
B. 3142  
C. 1342  
D. 4321

**正确答案**：B

**详细解析**：

**Scaled Dot-Product Attention公式**：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) * V
```

**正确执行顺序（3142）**：

**步骤3：计算QK^T并缩放**

```python
attn = ops.matmul(query, key.swapaxes(-2,-1)) / scaling_factor
```

- 计算Q和K的转置矩阵的点积
- 除以scaling factor（√d_k，通常是hidden_size的开方）
- 得到注意力分数矩阵

**步骤1：应用注意力掩码**

```python
if attn_mask is not None:
    attn = attn.masked_fill(attn_mask, -1e9)
```

- **为什么在softmax之前**：
    - 掩码用于标识padding或无效位置
    - 填充-1e9这样的极小值
    - 经过softmax后会变成接近0的值
- **作用**：屏蔽无语义意义的token

**步骤4：Softmax归一化**

```python
attn = self.softmax(attn)
```

- 将注意力分数转换为概率分布
- 保证权重在0-1之间
- 所有权重和为1

**步骤2：加权求和**

```python
output = ops.matmul(attn, value)
```

- 注意力权重与value做矩阵乘
- 得到最终的注意力输出

**关键理解**：

1. **掩码必须在softmax之前**：因为要通过极小值让softmax输出接近0
2. **缩放因子的作用**：防止点积结果过大导致softmax梯度消失
3. **完整流程**：QK^T → 缩放 → 掩码 → Softmax → 乘V

### 题目3：Transformer前馈网络实现（高教组）

**题目**：在基于MindSpore框架实现Transformer的Feed-Forward Network中，我们在"******"处应该填写什么代码，从而对输入进行非线性变换？（单选题）

A. 空白1: `self.activation = nn.GELU()`  
空白2: `x = self.activation(x)`

B. 空白1: `self.dense = nn.Dense(in_features, hidden_features)`  
空白2: `x = self.dense(x)`

C. 空白1: `self.dropout = nn.Dropout(p=1.0-keep_prob)`  
空白2: `x = self.dropout(x)`

D. 空白1: `self.attn_matmul_v = ops.BatchMatMul()`  
空白2: `x = self.attn_matmul_v(x)`

**正确答案**：A

**详细解析**：

**前馈神经网络(FFN)结构**：

```
Input → Linear1(升维) → Activation → Dropout → Linear2(降维) → Output
```

**代码结构分析**：

```python
class FeedForward(nn.Cell):
    def __init__(self, in_features, hidden_features, keep_prob):
        super().__init__()
        self.dense1 = nn.Dense(in_features, hidden_features)  # 已实现
        # ****** 空白1：需要添加激活函数 ******
        self.dropout = nn.Dropout(p=1.0-keep_prob)  # 已实现
        self.dense2 = nn.Dense(hidden_features, in_features)  # 已实现
    
    def construct(self, x):
        x = self.dense1(x)  # 第一层全连接
        # ****** 空白2：应用激活函数 ******
        x = self.dropout(x)  # Dropout
        x = self.dense2(x)  # 第二层全连接
        return x
```

**各选项分析**：

**A选项（正确）** ✅：

- **GELU激活函数**：Gaussian Error Linear Unit
- **作用**：提供非线性变换
- **位置**：在两个全连接层之间
- **为什么选GELU**：Transformer通常使用GELU而非ReLU
- **公式**：GELU(x) = x * Φ(x)，其中Φ是标准正态分布的累积分布函数

**B选项（错误）**：

- 这是添加另一个线性层
- 代码中已有dense1和dense2
- 不是非线性变换

**C选项（错误）**：

- Dropout已在代码中实现
- Dropout用于正则化，不是激活函数
- 不提供非线性变换

**D选项（错误）**：

- BatchMatMul用于批量矩阵乘法
- 通常用于注意力机制
- 不是FFN中的组件

**前馈网络的作用**：

1. **升维-降维**：增加模型表达能力
2. **非线性变换**：通过激活函数引入非线性
3. **特征提取**：对每个位置独立进行特征变换

**常用激活函数对比**：

- **ReLU**：简单高效，但可能导致神经元死亡
- **GELU**：平滑、可微，Transformer常用
- **Swish**：自门控，性能优秀但计算量大

### 题目4：静态图模式设置（高教组）

**题目**：目前已有基于MindSpore实现的网络Network，并定义了一个函数(run)用于进行模型的正向计算。某同学发现代码运行较慢，计划开启静态图模式进行加速，以下哪种方式描述是错误的？（单选题）

A. 使用`mindspore.set_context(mode=mindspore.GRAPH_MODE)`进行全局设置  
B. 在run函数上使用`mindspore.jit`修饰器，这样在调用该函数时，该模块自动被编译为静态图  
C. 使用`mindspore.jit_class()`进行全局设置  
D. 在调用run函数前，添加一行`run_with_jit=mindspore.jit(run)`，通过函数变换方式调用jit方法

**正确答案**：C

**详细解析**：

**MindSpore图模式概念**：

- **动态图（PyNative模式）**：逐行执行，灵活但较慢
- **静态图（Graph模式）**：先编译后执行，速度快但灵活性较低

**各选项分析**：

**A选项（正确）** ✅：

```python
import mindspore as ms
ms.set_context(mode=ms.GRAPH_MODE)
```

- **作用**：全局设置为静态图模式
- **效果**：整个程序都以静态图方式编译执行
- **适用场景**：整体性能优化

**B选项（正确）** ✅：

```python
@ms.jit
def run(model, data):
    output = model(data)
    return output
```

- **作用**：函数级即时编译
- **效果**：被装饰的函数以图编译方式执行
- **适用场景**：局部性能提升，其他部分保持灵活性

**C选项（错误）** ❌：

```python
# 错误用法
ms.jit_class()  # 这不是全局设置方法

# 正确用法
@ms.jit_class
class MyModel(nn.Cell):
    def __init__(self):
        super().__init__()
        # ...
```

- **`jit_class`不是全局设置方法**
- **正确用法**：作为装饰器装饰类（通常是nn.Cell）
- **作用范围**：仅对被装饰的类生效

**D选项（正确）** ✅：

```python
def run(model, data):
    output = model(data)
    return output

# 通过函数变换方式
run_with_jit = ms.jit(run)
result = run_with_jit(model, data)
```

- **作用**：函数变换式即时编译
- **效果**：与装饰器方式相同
- **适用场景**：不想修改原函数定义时

**三种加速方式对比**：

|方式|作用范围|灵活性|适用场景|
|---|---|---|---|
|set_context(GRAPH_MODE)|全局|低|生产环境，追求极致性能|
|@jit装饰器|函数级|中|局部优化，保留调试灵活性|
|jit(func)函数变换|函数级|中|不修改原函数定义|

**最佳实践**：

1. **开发阶段**：使用PyNative模式，便于调试
2. **优化阶段**：使用@jit装饰关键函数
3. **生产阶段**：使用GRAPH_MODE全局加速

resize_op = vision.Resize(size=(32, 32))

### 题目6：类别不平衡问题解决（高教组）

**题目**：在医疗影像分类任务中，正样本(患病)占比仅5%，负样本占比95%。训练时模型对负样本预测准确率高，但对正样本几乎无法识别。以下哪些方法可以有效缓解此问题？（多选题）

A. 对负样本进行欠采样(Under-sampling)  
B. 在损失函数中为不同类别分配权重(如增加正样本的权重)  
C. 对正样本进行数据增强(Data Augmentation)  
D. 对输入数据进行标准化(Normalization)

**正确答案**：ABC

**详细解析**：

**问题诊断**：

- **类别不平衡**：正样本5% vs 负样本95%
- **模型偏向多数类**：对负样本准确率高，对正样本识别差

**解决方案分类**：

**一、数据层面方法**：

**A选项：欠采样（正确）** ✅

```python
# 减少负样本数量
from imblearn.under_sampling import RandomUnderSampler

rus = RandomUnderSampler(random_state=42)
X_resampled, y_resampled = rus.fit_resample(X, y)
```

- **作用**：减少负样本（多数类）数目
- **优点**：平衡类别分布，减少训练时间
- **缺点**：可能丢失有用信息
- **适用**：数据量大，多数类冗余时

**C选项：数据增强（正确）** ✅

```python
# 增加正样本数量
augmentation = [
    vision.RandomHorizontalFlip(prob=0.5),
    vision.RandomRotation(degrees=15),
    vision.RandomColorAdjust(brightness=0.2)
]
```

- **作用**：增加正样本（少数类）数目
- **优点**：不丢失信息，增加数据多样性
- **方法**：
    - 图像：旋转、翻转、裁剪、色彩变换
    - 文本：同义词替换、回译
- **适用**：少数类样本质量高时

**二、算法层面方法**：

**B选项：类别加权（正确）** ✅

```python
# 在损失函数中增加正样本权重
class_weight = {
    0: 1.0,   # 负样本权重
    1: 19.0   # 正样本权重（95/5≈19）
}

loss_fn = nn.CrossEntropyLoss(weight=ms.Tensor([1.0, 19.0]))
```

- **作用**：增加对正样本（少数类）的关注
- **原理**：通过权重放大少数类的损失
- **优点**：简单有效，不改变数据
- **权重计算**：通常使用 `n_samples / (n_classes * n_samples_per_class)`

**D选项：标准化（错误）** ❌

```python
normalize_op = vision.Normalize(mean=[0.485], std=[0.229])
```

- **作用**：数据预处理的常规操作
- **效果**：对解决类别不平衡**没有帮助**
- **说明**：标准化是必要的，但不能解决类别不平衡问题

**类别不平衡解决方案总结**：

|方法类别|具体方法|优点|缺点|
|---|---|---|---|
|**数据层面**|过采样|增加少数类样本|可能过拟合|
||欠采样|减少多数类样本|可能丢失信息|
||SMOTE|合成新样本|可能引入噪声|
||数据增强|不丢失信息|需要领域知识|
|**算法层面**|类别加权|简单有效|需要调整权重|
||Focal Loss|关注困难样本|需要调整超参数|
||代价敏感学习|考虑误分类代价|实现复杂|
|**模型层面**|集成学习|提高稳定性|计算开销大|
||异常检测|适合极端不平衡|改变问题框架|

**最佳实践**：

1. **组合使用**：数据增强 + 类别加权效果最好
2. **评估指标**：使用F1-score、AUC-ROC而非准确率
3. **业务权衡**：考虑假阳性和假阴性的代价

### 题目7：网络参数获取（高教组）

**题目**：某同学基于MindSpore构造神经网络层，并实例化为net后，希望获取网络层的参数。已知网络层中有四个参数: w、b、mean、var，其中w和b为可训练参数，mean和var为不可训练参数。以下操作正确的是哪几项？（多选题）

A. 单独获取b的参数值: `net.b.asnumpy()`  
B. 获取mean和var的参数信息（包含名称、Tensor形状、数据类型等）: `net.trainable_params()`

        super().__init__()

        self.bn1 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1)
        self.bn2 = nn.BatchNorm2d(out_channels)

        identity = x

        out = self.bn1(out)
        out = self.relu(out)

**正确顺序：52413**

**步骤5：定义超参、损失函数、优化器**

```python

- **必须最先定义**：这些是训练的基础配置

def train_step(data, label):
    # 前向计算 + 反向传播
    (loss, logits), grads = grad_fn(data, label)
    # 参数更新
    optimizer(grads)
    return loss, logits
```

- **作用**：将前向、反向、更新封装为一个函数
- **包含**：梯度计算 + 参数更新

```python
# 第五步：训练循环
for epoch in range(epochs):
    for data, label in dataset:
        loss, logits = train_step(data, label)
        print(f"Epoch: {epoch}, Loss: {loss}")
```

- **作用**：遍历数据集，执行多轮训练
- **每轮**：遍历所有batch，调用train_step

**完整训练代码示例**：

```python

from mindspore import Tensor

# 步骤5：定义超参、损失函数、优化器

# 步骤2：定义正向函数
def forward_fn(data, label):
    logits = model(data)
    loss = loss_fn(logits, label)
    return loss, logits

# 步骤4：获得微分函数

                             weights=optimizer.parameters,
                             has_aux=True)

# 步骤1：封装train_step

    (loss, logits), grads = grad_fn(data, label)

    for data, label in dataset.create_tuple_iterator():
        loss, logits = train_step(data, label)
```

**为什么是这个顺序**：

1. **逻辑依赖**：后面的步骤依赖前面定义的组件
2. **函数式编程**：先定义基础函数，再进行函数变换，最后封装使用
3. **MindSpore特色**：通过函数变换实现自动微分

### 题目10：过拟合问题解决（高职组）

**题目**：小华在基于MindSpore训练一个LSTM文本情感分类模型时，训练集准确率达到95%，但验证集准确率仅为60%，且验证Loss持续上升。此时最应采取的措施是什么？（单选题）

A. 增加训练轮次(Epochs)

C. 改用更大的预训练模型

**正确答案**：B

**详细解析**：

**问题诊断**：

- **训练集准确率95%，验证集准确率60%** → 典型的过拟合
- **验证Loss持续上升** → 模型在验证集上表现越来越差

**什么是过拟合**：

- 模型在训练集上表现很好
- 但在未见过的数据（验证集/测试集）上表现很差
- 原因：模型过度依赖训练集的特征，泛化能力差

**各选项分析**：

**A选项：增加训练轮次** ❌

```python
# 错误做法

```

- **后果**：加剧过拟合
- **原因**：已经过拟合，继续训练只会更严重
- **反而应该**：提前停止训练（Early Stopping）

**B选项：添加Dropout层** ✅

```python

        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)

        # 添加Dropout层

        x = self.fc(x)

```

- **作用**：随机丢弃神经元，防止过拟合
- **原理**：
    - 训练时：随机将部分神经元输出置为0
    - 测试时：使用所有神经元（自动缩放）
- **优点**：
    - 有效防止过拟合
    - 相当于训练多个子网络的集成
- **常用位置**：全连接层之前

- **作用**：将token ID映射为dense vector（词向量）
- **输出**：Embedding向量，shape: `(batch_size, seq_len, embed_dim)`
- **为什么第一**：
    - 文本必须先转换为数字表示
    - 模型才能进行数值计算

**2. RNN层（序列建模）**

```python
        # 第二层：RNN
        self.rnn = nn.RNN(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=2,
            batch_first=True
        )
```

- **输入**：Embedding向量序列
- **作用**：捕捉序列中的时序信息和上下文依赖
- **输出**：
    - `output`: 所有时间步的隐藏状态
    - `hn`: 最后一个时间步的隐藏状态
- **用途**：提取文本的语义特征

**3. Dense层（分类层，必须在最后）**

```python
        # 第三层：全连接/分类层
        self.fc = nn.Dense(hidden_dim, num_classes)
    
    def construct(self, x):
        # x shape: (batch_size, seq_len)
        x = self.embedding(x)  # (batch_size, seq_len, embed_dim)
        output, hn = self.rnn(x)  # hn: (num_layers, batch_size, hidden_dim)
        
        # 使用最后一层的隐藏状态
        x = hn[-1]  # (batch_size, hidden_dim)
        
        # 分类
        x = self.fc(x)  # (batch_size, num_classes)
        return x
```

- **输入**：RNN的最后隐藏状态
- **作用**：将特征映射到类别空间
- **输出维度**：等于分类类别数
- **为什么最后**：
    - 需要先提取特征（RNN）
    - 再进行分类决策（Dense）

**各选项分析**：

**A选项：Embedding → Dense → RNN** ❌

```python
# 错误结构
x = self.embedding(x)  # (B, L, E)
x = self.dense(x)      # 在RNN前分类？错误！
x, _ = self.rnn(x)
```

- **问题**：在RNN前就进行分类没有意义
- **RNN应该在Dense前**：先提取特征，再分类

**B选项：Embedding → RNN → Dense** ✅

```python
# 正确结构
x = self.embedding(x)   # Token ID → Embedding
output, hn = self.rnn(x)  # 序列建模
x = self.fc(hn[-1])     # 分类
```

- **逻辑正确**：文本 → 词向量 → 序列特征 → 分类
- **符合NLP标准流程**

**C选项：Dense → Embedding → RNN** ❌

```python

x = self.embedding(x)  # Embedding必须在最前
```

- **问题**：
    - token ID是整数索引，不能直接输入Dense层
    - Embedding必须是第一步

**D选项：Embedding → RNN** ❌

```python
# 不完整结构

return hn  # 直接返回隐藏状态？
```

- **问题**：缺少分类层
- **RNN输出是特征，不是类别**
- **必须有Dense层映射到类别空间**

```python
import mindspore.nn as nn
import mindspore as ms

class SentimentRNN(nn.Cell):
    def __init__(self, 
                 vocab_size=10000,    # 词表大小
                 embed_dim=128,       # 词向量维度
                 hidden_dim=256,      # RNN隐藏层维度
                 num_classes=2):      # 分类数（正面/负面）
        super().__init__()
        
        # 1. Embedding层：将token ID转为词向量
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        
        # 2. RNN层：提取序列特征
        self.rnn = nn.RNN(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=2,
            batch_first=True,
            dropout=0.5
        )
        
        # 3. Dropout：防止过拟合
        self.dropout = nn.Dropout(keep_prob=0.5)
        
        # 4. Dense层：分类
        self.fc = nn.Dense(hidden_dim, num_classes)
    
    def construct(self, x):
        """
        Args:
            x: token ID序列, shape (batch_size, seq_len)
        Returns:
            logits: 分类logits, shape (batch_size, num_classes)
        """
        # Step 1: Token ID → Embedding
        x = self.embedding(x)  # (B, L, E)
        
        # Step 2: Embedding → RNN特征
        output, hn = self.rnn(x)
        # output: (B, L, H) - 所有时间步的输出
        # hn: (num_layers, B, H) - 最后时间步各层的隐藏状态
        
        # Step 3: 使用最后一层的隐藏状态
        x = hn[-1]  # (B, H)
        
        # Step 4: Dropout
        x = self.dropout(x)
        
        # Step 5: 分类
        logits = self.fc(x)  # (B, num_classes)
        
        return logits

# 使用示例

- **梯度消失问题**：
    - 深层网络反向传播时
    - 梯度不断相乘
    - 梯度值越来越小
    - 底层网络几乎不更新
- **BatchNorm如何解决**：
    1. **归一化激活值**：
        - 保持激活值在合理范围
        - 避免进入饱和区
    2. **稳定梯度**：
        - 梯度不会过大或过小
        - 更容易反向传播
    3. **类似残差连接**：
        - γ和β参数提供恒等映射的可能
        - 梯度可以直接传播
- **效果**：
    - 可以训练更深的网络
    - VGG、ResNet等都使用BN
- **结论**：✅ 正确

**BatchNorm详细说明**：

**1. 工作机制**：

```python
class CustomBatchNorm(nn.Cell):
    def __init__(self, num_features, eps=1e-5, momentum=0.9):
        super().__init__()
        # 可学习参数
        self.gamma = ms.Parameter(ms.ops.ones(num_features))
        self.beta = ms.Parameter(ms.ops.zeros(num_features))
        
        # 移动平均（推理时使用）
        self.moving_mean = ms.Parameter(ms.ops.zeros(num_features), 
                                        requires_grad=False)
        self.moving_var = ms.Parameter(ms.ops.ones(num_features), 
                                       requires_grad=False)
        self.eps = eps
        self.momentum = momentum
    
    def construct(self, x):
        if self.training:
            # 训练模式：使用当前batch统计量
            mean = x.mean(axis=0)
            var = x.var(axis=0)
            
            # 更新移动平均
            self.moving_mean = (self.momentum * self.moving_mean + 
                               (1 - self.momentum) * mean)
            self.moving_var = (self.momentum * self.moving_var + 
                              (1 - self.momentum) * var)
        else:
            # 推理模式：使用移动平均
            mean = self.moving_mean
            var = self.moving_var
        
        # 归一化
        x_norm = (x - mean) / ms.ops.sqrt(var + self.eps)
        
        # 缩放和平移
        out = self.gamma * x_norm + self.beta
        return out
```

**2. 训练 vs 推理**：

```python
# 训练时
model.set_train(True)
# 使用当前batch的均值和方差
# 更新移动平均统计量

# 推理时
model.set_train(False)
# 使用训练时累积的移动平均
# 保证推理结果稳定
```

**3. 不同维度的BatchNorm**：

```python
# 1D: 用于全连接层或RNN
bn1d = nn.BatchNorm1d(features)
# 输入shape: (N, C) 或 (N, C, L)

# 2D: 用于卷积层（图像）

# 输入shape: (N, C, H, W)

# 3D: 用于3D卷积（视频）

# 输入shape: (N, C, D, H, W)
```

**BatchNorm优缺点总结**：

**优点**：

- ✅ 加速训练（2-3倍）
- ✅ 允许更大学习率
- ✅ 提高泛化能力
- ✅ 缓解梯度消失
- ✅ 减少对初始化的依赖
- ✅ 有正则化效果

**缺点**：

- ❌ 依赖batch size
    - batch size太小效果差
    - 建议batch size >= 32
- ❌ 推理时需要保存统计量
- ❌ RNN中效果不明显
- ❌ 小batch或单样本推理可能不稳定

**替代方案**：

```python

# 2. GroupNorm: 介于BN和LN之间

# 3. InstanceNorm: 用于风格迁移

```

**最佳实践**：

1. **CV任务**：优先使用BatchNorm2d
2. **NLP任务**：优先使用LayerNorm
3. **小batch**：使用GroupNorm或LayerNorm
4. **GAN**：考虑使用InstanceNorm

### 题目12：类别不平衡损失函数（高职组）

**题目**：在金融领域的欺诈检测问题中，正样本（欺诈交易）往往远少于负样本（正常交易）。小华在基于MindSpore训练一个信用卡欺诈检测模型时，正样本（欺诈）占比不足1%，以下哪种损失函数最适合此场景？（单选题）

A. mindspore.nn.CrossEntropyLoss  
B. mindspore.nn.FocalLoss  
C. mindspore.nn.MSELoss  
D. mindspore.nn.L1Loss

**正确答案**：B

**详细解析**：

**问题特点**：

- **极度类别不平衡**：正样本<1%，负样本>99%
- **任务类型**：二分类（欺诈 vs 正常）
- **业务要求**：必须准确识别少数类（欺诈）

**各选项分析**：

**A选项：CrossEntropyLoss**

```python
loss_fn = nn.CrossEntropyLoss()
```

- **作用**：标准的分类损失函数
- **公式**：`Loss = -log(p_correct_class)`
- **优点**：
    - 简单易用
    - 适用于一般分类任务
- **缺点**：
    - 对类别不平衡不敏感
    - 容易被多数类主导
    - 少数类梯度贡献小
- **结论**：可以用，但不是最适合 ⭐⭐⭐

**B选项：FocalLoss** ✅

```python
loss_fn = nn.FocalLoss(
    gamma=2.0,  # 聚焦参数
    alpha=0.25  # 类别权重
)
```

- **作用**：专门为类别不平衡设计的损失函数
- **公式**：`FL = -α(1-p)^γ * log(p)`
- **核心思想**：
    1. **降低易分样本的权重**：通过`(1-p)^γ`项
    2. **提高难分样本的权重**：p小时权重大
    3. **平衡类别**：通过α参数调节
- **参数说明**：
    - **γ (gamma)**：聚焦参数
        - γ=0：退化为标准交叉熵
        - γ=2：常用值，效果好
        - 越大越关注困难样本
    - **α (alpha)**：类别权重
        - 用于平衡正负样本
        - 少数类设置较大值
- **优点**：
    - ⭐⭐⭐⭐⭐ 极度不平衡场景最佳
    - 自动关注困难样本
    - 同时解决类别不平衡和难易样本问题
- **适用场景**：
    - 目标检测（one-stage）
    - 欺诈检测
    - 异常检测
    - 医疗诊断
- **结论**：**最适合** ✅

**C选项：MSELoss**

```python
loss_fn = nn.MSELoss()

- **作用**：均方误差损失
- **公式**：`MSE = mean((pred - target)²)`
- **适用**：回归任务
- **问题**：
    - 用于回归，不适合分类
    - 不能处理类别不平衡
- **结论**：不适合 ❌

loss_fn = nn.L1Loss()

- **公式**：`L1 = mean(|pred - target|)`

**FocalLoss详细说明**：

**1. 标准交叉熵的问题**：

```python
# 假设100个样本，99个负样本（容易分对），1个正样本（难分）
# 负样本平均loss: 0.01 × 99 = 0.99
# 正样本loss: 1.0 × 1 = 1.0
# 总loss被易分的负样本主导！
```

**2. FocalLoss如何解决**：

```python
# 易分样本（p=0.9）：
# FL = -(1-0.9)^2 * log(0.9) = -0.01 * 0.105 = 0.00105

# 难分样本（p=0.3）：
# FL = -(1-0.3)^2 * log(0.3) = -0.49 * 1.204 = 0.590

# 难分样本的loss贡献是易分样本的560倍！
```

**3. 实际应用代码**：

```python
import mindspore.nn as nn
import mindspore as ms

class FraudDetectionModel(nn.Cell):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Dense(30, 64)
        self.relu = nn.ReLU()
        self.dropout = nn.Dropout(keep_prob=0.5)
        self.fc2 = nn.Dense(64, 2)
    
    def construct(self, x):
        x = self.fc1(x)
        x = self.relu(x)
        x = self.dropout(x)
        x = self.fc2(x)
        return x

# 使用FocalLoss
model = FraudDetectionModel()
loss_fn = nn.FocalLoss(
    gamma=2.0,      # 关注困难样本
    alpha=0.99,     # 欺诈类权重（因为占比1%）
    reduction='mean'
)
optimizer = nn.Adam(model.trainable_params(), learning_rate=0.001)

# 训练
def train_step(data, label):
    def forward_fn(data, label):
        logits = model(data)
        loss = loss_fn(logits, label)
        return loss
    
    grad_fn = ms.value_and_grad(forward_fn, None, 
                                 weights=optimizer.parameters)
    loss, grads = grad_fn(data, label)
    optimizer(grads)
    return loss
```

### 题目2：服务器显存计算（高教组）

**题目**：一家小型科技公司想采用昇腾+CANN搭建了集群平台来运行其基于开源模型自主研发的大模型应用，现在正在采购对应的计算服务器。假设目前该公司想采用Atlas 800TA2服务器进行训练适配，模型大小为67B，服务器A型一共内置8个NPU芯片，每块芯片显存为64G，该公司的微调方法为LORA(FP16)，假设调节的参数量较小，相对于原模型可以忽略不计，那么其至少需要准备几台Atlas 800 TA2服务器？（单选题）

A. 1台服务器  
B. 2台服务器  
C. 3台服务器  
D. 4台服务器

**正确答案**：C

**详细解析**：

**知识点**：LORA微调显存计算

**计算步骤**：
1. **LORA微调显存占用**：理想显存占用 = 模型权重占用 + 优化器状态占用
2. **题目条件**：调节的参数量较小，相对于原模型可以忽略不计，所以只需计算模型权重占用
3. **模型显存占用计算**：
   - 公式：模型参数量 × 精度对应字节数
   - FP16精度对应2个字节
   - 显存占用 = 67B × 2(B/param) × 1024³ / 1024⁹ = 134G
4. **服务器显存**：每台服务器 = 8 × 64G = 512G
5. **所需服务器数量**：134G ÷ 512G ≈ 0.26台，但134G需要完整存储，一台不够
   - 实际计算：134G / 512G < 1，但考虑到完整部署需要，至少需要3台

**注意**：原题中的67B应为671B（根据后续相关题目），如果是671B：
- 显存占用 = 671B × 2 × 1024³ / 1024⁹ = 1342G
- 所需服务器 = 1342G ÷ 512G ≈ 2.62台，向上取整需要3台

### 题目2：Scaled Dot-Product Attention计算（高教组）

**题目**：注意力机制能够帮助模型在输入序列中选择性关注某些部分，从而提高模型表示能力。根据公式，在基于MindSpore计算scaled dot-product attention的过程中，下列关键步骤排序正确的选项是哪一个？（单选题）

```python
from mindspore import ops

1. 通过attn_mask进行注意力掩码
if attn_mask is not None:
    attn = attn.masked_fill(attn_mask, -1e9)

2. 注意力权重与value做矩阵乘
output = ops.matmul(attn, value)

3. 计算得到scaling factor后，通过ops.matmul计算query和key的点积，并除以scaling factor
attn = ops.matmul(query, key.swapaxes(-2,-1)) / scaling_factor

4. softmax使权重保证在0-1之间
attn = self.softmax(attn)
```

A. 3412  
B. 3142  
C. 1342  
D. 4321

**正确答案**：B

**详细解析**：

**Scaled Dot-Product Attention公式**：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) * V
```

**正确执行顺序（3142）**：

**步骤3：计算QK^T并缩放**

```python
attn = ops.matmul(query, key.swapaxes(-2,-1)) / scaling_factor
```

- 计算Q和K的转置矩阵的点积
- 除以scaling factor（√d_k，通常是hidden_size的开方）
- 得到注意力分数矩阵

**步骤1：应用注意力掩码**

```python
if attn_mask is not None:
    attn = attn.masked_fill(attn_mask, -1e9)
```

- **为什么在softmax之前**：
    - 掩码用于标识padding或无效位置
    - 填充-1e9这样的极小值
    - 经过softmax后会变成接近0的值
- **作用**：屏蔽无语义意义的token

**步骤4：Softmax归一化**

```python
attn = self.softmax(attn)
```

- 将注意力分数转换为概率分布
- 保证权重在0-1之间
- 所有权重和为1

**步骤2：加权求和**

```python
output = ops.matmul(attn, value)
```

- 注意力权重与value做矩阵乘
- 得到最终的注意力输出

**关键理解**：

1. **掩码必须在softmax之前**：因为要通过极小值让softmax输出接近0
2. **缩放因子的作用**：防止点积结果过大导致softmax梯度消失
3. **完整流程**：QK^T → 缩放 → 掩码 → Softmax → 乘V

### 题目3：Transformer前馈网络实现（高教组）

**题目**：在基于MindSpore框架实现Transformer的Feed-Forward Network中，我们在"******"处应该填写什么代码，从而对输入进行非线性变换？（单选题）

空白2: `x = self.attn_matmul_v(x)`

**正确答案**：A

**详细解析**：

**前馈神经网络(FFN)结构**：

```
Input → Linear1(升维) → Activation → Dropout → Linear2(降维) → Output
```

**代码结构分析**：

```python
class FeedForward(nn.Cell):
    def __init__(self, in_features, hidden_features, keep_prob):
        super().__init__()
        self.dense1 = nn.Dense(in_features, hidden_features)  # 已实现
        # ****** 空白1：需要添加激活函数 ******
        self.dropout = nn.Dropout(p=1.0-keep_prob)  # 已实现
        self.dense2 = nn.Dense(hidden_features, in_features)  # 已实现
    
    def construct(self, x):
        x = self.dense1(x)  # 第一层全连接
        # ****** 空白2：应用激活函数 ******
        x = self.dropout(x)  # Dropout
        x = self.dense2(x)  # 第二层全连接
        return x
```

**各选项分析**：

**A选项（正确）** ✅：

- **GELU激活函数**：Gaussian Error Linear Unit
- **作用**：提供非线性变换
- **位置**：在两个全连接层之间
- **为什么选GELU**：Transformer通常使用GELU而非ReLU
- **公式**：GELU(x) = x * Φ(x)，其中Φ是标准正态分布的累积分布函数

**B选项（错误）**：

- 这是添加另一个线性层
- 代码中已有dense1和dense2
- 不是非线性变换

**C选项（错误）**：

- Dropout已在代码中实现
- Dropout用于正则化，不是激活函数
- 不提供非线性变换

**D选项（错误）**：

- BatchMatMul用于批量矩阵乘法
- 通常用于注意力机制
- 不是FFN中的组件

**前馈网络的作用**：

1. **升维-降维**：增加模型表达能力
2. **非线性变换**：通过激活函数引入非线性
3. **特征提取**：对每个位置独立进行特征变换

**常用激活函数对比**：

- **ReLU**：简单高效，但可能导致神经元死亡
- **GELU**：平滑、可微，Transformer常用

```python
@ms.jit
def run(model, data):

    return output
```

- **作用**：函数级即时编译
- **效果**：被装饰的函数以图编译方式执行
- **适用场景**：局部性能提升，其他部分保持灵活性

**C选项（错误）** ❌：

**最佳实践**：

1. **开发阶段**：使用PyNative模式，便于调试

**问题诊断**：

**解决方案分类**：

**一、数据层面方法**：

**A选项：欠采样（正确）** ✅

- **优点**：平衡类别分布，减少训练时间

**C选项：数据增强（正确）** ✅

- **作用**：增加正样本（少数类）数目
- **优点**：不丢失信息，增加数据多样性
- **方法**：
    - 图像：旋转、翻转、裁剪、色彩变换
    - 文本：同义词替换、回译

**二、算法层面方法**：

**B选项：类别加权（正确）** ✅

- **作用**：增加对正样本（少数类）的关注
- **原理**：通过权重放大少数类的损失
- **优点**：简单有效，不改变数据
- **权重计算**：通常使用 `n_samples / (n_classes * n_samples_per_class)`

**D选项：标准化（错误）** ❌

- **作用**：数据预处理的常规操作

**类别不平衡解决方案总结**：

|方法类别|具体方法|优点|缺点|
|---|---|---|---|
|**数据层面**|过采样|增加少数类样本|可能过拟合|
||欠采样|减少多数类样本|可能丢失信息|
||SMOTE|合成新样本|可能引入噪声|
||数据增强|不丢失信息|需要领域知识|
|**算法层面**|类别加权|简单有效|需要调整权重|

|**模型层面**|集成学习|提高稳定性|计算开销大|
||异常检测|适合极端不平衡|改变问题框架|

**最佳实践**：

1. **组合使用**：数据增强 + 类别加权效果最好
2. **评估指标**：使用F1-score、AUC-ROC而非准确率
3. **业务权衡**：考虑假阳性和假阴性的代价

### 题目8：ResNet50网络构建（高教组）

**题目**：在基于MindSpore构建ResNet网络时，主要可以分解为以下步骤：

对构建ResNet50网络的细节描述，哪些是正确的？（多选题）

**ResNet残差网络核心思想**：

- **残差连接**：输出 = F(x) + x
- **解决问题**：深层网络的梯度消失和退化问题
- **优势**：更容易优化，可以训练更深的网络

        self.layer1 = nn.SequentialCell([
            ResidualBlock(64, 64),
            ResidualBlock(64, 64),
            ResidualBlock(64, 64)
        ])
        # ... 其他层
```

- **作用**：避免重复编写代码
- **优点**：
    - 代码简洁
    - 结构清晰
    - 易于维护
- **适用场景**：残差块结构相似，只是参数不同

**B选项（错误）** ❌

```python
# 错误示例：shape不一致会报错
class ResidualBlock(nn.Cell):
    def construct(self, x):
        identity = x  # shape: (B, C1, H, W)
        out = self.conv1(x)  # shape: (B, C2, H, W)
        out = self.conv2(out)
        # 如果C1 != C2，直接相加会报错！
        out = out + identity  # ❌ 错误！
        return out

# 正确做法：使用shortcut调整shape
class ResidualBlock(nn.Cell):
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, 1, 1)
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1)
        
        # shortcut: 调整输入shape与输出一致
        if in_channels != out_channels:
            self.shortcut = nn.Conv2d(in_channels, out_channels, 1, 1, 0)
        else:
            self.shortcut = nn.Identity()
    
    def construct(self, x):
        identity = self.shortcut(x)  # 调整shape
        out = self.conv1(x)
        out = self.conv2(out)
        out = out + identity  # ✅ 正确！
        return out
```

- **问题**：x与F(x)的shape必须一致才能相加
- **解决方案**：
    - **情况1**：维度相同 → 直接相加
    - **情况2**：维度不同 → 使用1×1卷积调整
    - **情况3**：尺寸不同 → 使用stride或pooling调整

**C选项（正确）** ✅

```python
import mindspore.nn as nn

class ResidualBlock(nn.Cell):
    def __init__(self, in_channels, out_channels):
        """重写__init__方法，定义网络层"""
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, out_channels, 3, 1, 1)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(out_channels, out_channels, 3, 1, 1)
        self.bn2 = nn.BatchNorm2d(out_channels)
    
    def construct(self, x):
        """重写construct方法，定义前向计算逻辑"""
        identity = x
        out = self.conv1(x)
        out = self.bn1(out)
        out = self.relu(out)
        out = self.conv2(out)
        out = self.bn2(out)
        out = out + identity
        out = self.relu(out)
        return out
```

- **标准做法**：继承nn.Cell类
- **必须重写**：
    - `__init__`：定义网络层
    - `construct`：定义前向计算逻辑

**D选项（正确）** ✅

class ResNet50(nn.Cell):

```

- **全连接层作用**：将特征映射到类别空间

### 题目9：MindSpore训练逻辑定义（高职组）

**题目**：以下对使用MindSpore定义模型训练逻辑的描述中，排序正确的是哪一项？（单选题）

1. 将微分函数和优化器执行封装为train_step函数，实现单步训练逻辑
2. 定义正向函数forward_fn
3. 循环迭代数据集进行训练
4. 使用value_and_grad获得微分函数grad_fn
5. 定义超参(epoch, learning rate等)、损失函数、优化器

A. 35124  
B. 52413  
C. 25143  
D. 12345

**正确答案**：B

**详细解析**：

**MindSpore函数式编程范式**：

- **核心思想**：以函数为单位进行计算
- **优势**：清晰的计算流程，易于优化和并行

**正确顺序：52413**

**步骤5：定义超参、损失函数、优化器**

```python
# 第一步：定义训练所需的基本组件
epochs = 10
learning_rate = 0.001
loss_fn = nn.CrossEntropyLoss()
optimizer = nn.Adam(model.trainable_params(), learning_rate)
```

- **必须最先定义**：这些是训练的基础配置
- **包含内容**：
    - 超参数：epochs, batch_size, learning_rate
    - 损失函数：CrossEntropyLoss, MSELoss等
    - 优化器：Adam, SGD, Momentum等

**步骤2：定义正向函数forward_fn**

```python
# 第二步：定义前向计算逻辑
def forward_fn(data, label):
    logits = model(data)
    loss = loss_fn(logits, label)
    return loss, logits
```

- **作用**：定义如何从输入得到损失值
- **返回**：损失值和预测结果

**步骤4：使用value_and_grad获得微分函数**

```python
# 第三步：通过函数变换得到梯度计算函数
grad_fn = ms.value_and_grad(forward_fn, None, 
                             weights=optimizer.parameters, 
                             has_aux=True)
```

- **函数变换**：将前向函数转换为梯度计算函数
- **value_and_grad**：同时返回函数值和梯度
- **参数说明**：
    - `forward_fn`：要求导的函数
    - `None`：不对输入求导
    - `weights`：对哪些参数求导
    - `has_aux=True`：返回辅助输出（logits）

**步骤1：封装为train_step函数**

```python
# 第四步：封装单步训练逻辑
def train_step(data, label):
    # 前向计算 + 反向传播
    (loss, logits), grads = grad_fn(data, label)
    # 参数更新
    optimizer(grads)
    return loss, logits
```

- **作用**：将前向、反向、更新封装为一个函数
- **包含**：梯度计算 + 参数更新

**步骤3：循环迭代数据集**

```python
# 第五步：训练循环
for epoch in range(epochs):
    for data, label in dataset:
        loss, logits = train_step(data, label)
        print(f"Epoch: {epoch}, Loss: {loss}")
```

- **作用**：遍历数据集，执行多轮训练
- **每轮**：遍历所有batch，调用train_step

**完整训练代码示例**：

```python

from mindspore import Tensor

optimizer = nn.Adam(model.trainable_params(), learning_rate)

# 步骤2：定义正向函数
def forward_fn(data, label):
    logits = model(data)
    loss = loss_fn(logits, label)
    return loss, logits

# 步骤4：获得微分函数
grad_fn = ms.value_and_grad(forward_fn, None, 
                             weights=optimizer.parameters,
                             has_aux=True)

# 步骤1：封装train_step
def train_step(data, label):
    (loss, logits), grads = grad_fn(data, label)
    optimizer(grads)
    return loss, logits

# 步骤3：训练循环
for epoch in range(epochs):
    for data, label in dataset.create_tuple_iterator():
        loss, logits = train_step(data, label)
```

**为什么是这个顺序**：

1. **逻辑依赖**：后面的步骤依赖前面定义的组件
2. **函数式编程**：先定义基础函数，再进行函数变换，最后封装使用
3. **MindSpore特色**：通过函数变换实现自动微分

### 题目10：过拟合问题解决（高职组）

**题目**：小华在基于MindSpore训练一个LSTM文本情感分类模型时，训练集准确率达到95%，但验证集准确率仅为60%，且验证Loss持续上升。此时最应采取的措施是什么？（单选题）

A. 增加训练轮次(Epochs)  
B. 在模型中添加Dropout层  
C. 改用更大的预训练模型  
D. 提高学习率

**正确答案**：B

**详细解析**：

**问题诊断**：

- **训练集准确率95%，验证集准确率60%** → 典型的过拟合
- **验证Loss持续上升** → 模型在验证集上表现越来越差

**什么是过拟合**：

- 模型在训练集上表现很好
- 但在未见过的数据（验证集/测试集）上表现很差
- 原因：模型过度依赖训练集的特征，泛化能力差

**各选项分析**：

**A选项：增加训练轮次** ❌

```python
# 错误做法
epochs = 100  # 从10增加到100
```

- **后果**：加剧过拟合
- **原因**：已经过拟合，继续训练只会更严重
- **反而应该**：提前停止训练（Early Stopping）

**B选项：添加Dropout层** ✅

```python
import mindspore.nn as nn

class LSTMClassifier(nn.Cell):
    def __init__(self):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_size, batch_first=True)
        
        # 添加Dropout层
        self.dropout = nn.Dropout(keep_prob=0.5)  # 丢弃50%
        
        self.fc = nn.Dense(hidden_size, num_classes)
    
    def construct(self, x):
        x = self.embedding(x)
        output, (hn, cn) = self.lstm(x)
        
        # 在全连接层前使用Dropout
        x = self.dropout(hn[-1])
        
        x = self.fc(x)
        return x
```

- **作用**：随机丢弃神经元，防止过拟合
- **原理**：
    - 训练时：随机将部分神经元输出置为0
    - 测试时：使用所有神经元（自动缩放）
- **优点**：
    - 有效防止过拟合
    - 相当于训练多个子网络的集成
- **常用位置**：全连接层之前

**C选项：改用更大的预训练模型** ❌

```python
# 错误做法
model = BertLarge()  # 从LSTM改为更大的BERT
```

- **后果**：过拟合更严重
- **原因**：
    - 更大模型 = 更高复杂度
    - 更容易过拟合
    - 需要更多训练数据
- **什么时候用大模型**：
    - 数据量充足
    - 任务复杂度高
    - 有充分的正则化

**D选项：提高学习率** ❌

```python
# 错误做法
learning_rate = 0.01  # 从0.001提高到0.01
```

- **后果**：可能导致训练不稳定
- **问题**：
    - 学习率过高 → 参数更新步长大
    - 可能导致损失剧烈波动
    - 甚至出现"跑飞"（loss变为NaN）
- **反而应该**：适当降低学习率或使用学习率衰减

**解决过拟合的方法总结**：

|方法类别|具体方法|效果|适用场景|
|---|---|---|---|
|**正则化**|Dropout|⭐⭐⭐⭐⭐|深度网络|
||L1/L2正则|⭐⭐⭐⭐|任何模型|
||BatchNorm|⭐⭐⭐|深度网络|
|**数据增强**|文本增强|⭐⭐⭐⭐|NLP任务|
||图像增强|⭐⭐⭐⭐⭐|CV任务|
|**模型简化**|减少层数|⭐⭐⭐|小数据集|
||减少神经元|⭐⭐⭐|小数据集|
|**训练策略**|Early Stopping|⭐⭐⭐⭐⭐|任何场景|
||学习率衰减|⭐⭐⭐⭐|任何场景|
|**数据**|增加数据量|⭐⭐⭐⭐⭐|有条件时|

### 题目11：RNN情感分类模型结构（高职组）

**题目**：某同学正在基于MindSpore实现RNN情感分类任务，在该任务中，以下哪个是整体模型结构？（单选题）

A. nn.Embedding → nn.Dense → nn.RNN  
B. nn.Embedding → nn.RNN → nn.Dense  
C. nn.Dense → nn.Embedding → nn.RNN  
D. nn.Embedding → nn.RNN

**正确答案**：B

**详细解析**：

**NLP任务的通用流程**：

```
文本输入 → Token化 → Embedding → 序列模型 → 分类层 → 输出
```

**正确结构：Embedding → RNN → Dense**

**1. Embedding层（必须在最前面）**

```python
class SentimentClassifier(nn.Cell):
    def __init__(self, vocab_size, embed_dim):
        super().__init__()
        # 第一层：Embedding
        self.embedding = nn.Embedding(vocab_size, embed_dim)
```

- **输入**：文本的token ID序列，如 `[15, 234, 67, 89]`
- **作用**：将token ID映射为dense vector（词向量）
- **输出**：Embedding向量，shape: `(batch_size, seq_len, embed_dim)`
- **为什么第一**：
    - 文本必须先转换为数字表示
    - 模型才能进行数值计算

**2. RNN层（序列建模）**

```python
        # 第二层：RNN
        self.rnn = nn.RNN(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=2,
            batch_first=True
        )
```

- **输入**：Embedding向量序列
- **作用**：捕捉序列中的时序信息和上下文依赖
- **输出**：
    - `output`: 所有时间步的隐藏状态
    - `hn`: 最后一个时间步的隐藏状态
- **用途**：提取文本的语义特征

**3. Dense层（分类层，必须在最后）**

```python
        # 第三层：全连接/分类层
        self.fc = nn.Dense(hidden_dim, num_classes)
    
    def construct(self, x):
        # x shape: (batch_size, seq_len)
        x = self.embedding(x)  # (batch_size, seq_len, embed_dim)
        output, hn = self.rnn(x)  # hn: (num_layers, batch_size, hidden_dim)
        
        # 使用最后一层的隐藏状态
        x = hn[-1]  # (batch_size, hidden_dim)
        
        # 分类
        x = self.fc(x)  # (batch_size, num_classes)
        return x
```

- **输入**：RNN的最后隐藏状态
- **作用**：将特征映射到类别空间
- **输出维度**：等于分类类别数
- **为什么最后**：
    - 需要先提取特征（RNN）
    - 再进行分类决策（Dense）

**各选项分析**：

**A选项：Embedding → Dense → RNN** ❌

```python
# 错误结构
x = self.embedding(x)  # (B, L, E)
x = self.dense(x)      # 在RNN前分类？错误！
x, _ = self.rnn(x)
```

- **问题**：在RNN前就进行分类没有意义
- **RNN应该在Dense前**：先提取特征，再分类

**B选项：Embedding → RNN → Dense** ✅

```python
# 正确结构
x = self.embedding(x)   # Token ID → Embedding
output, hn = self.rnn(x)  # 序列建模
x = self.fc(hn[-1])     # 分类
```

- **逻辑正确**：文本 → 词向量 → 序列特征 → 分类
- **符合NLP标准流程**

**C选项：Dense → Embedding → RNN** ❌

```python
# 错误结构
x = self.dense(x)      # 对token ID分类？错误！
x = self.embedding(x)  # Embedding必须在最前
```

- **问题**：
    - token ID是整数索引，不能直接输入Dense层
    - Embedding必须是第一步

**D选项：Embedding → RNN** ❌

```python
# 不完整结构
x = self.embedding(x)
output, hn = self.rnn(x)
# 缺少分类层！
return hn  # 直接返回隐藏状态？
```

- **问题**：缺少分类层
- **RNN输出是特征，不是类别**
- **必须有Dense层映射到类别空间**

**完整的情感分类模型示例**：

```python
import mindspore.nn as nn
import mindspore as ms

class SentimentRNN(nn.Cell):
    def __init__(self, 
                 vocab_size=10000,    # 词表大小
                 embed_dim=128,       # 词向量维度
                 hidden_dim=256,      # RNN隐藏层维度
                 num_classes=2):      # 分类数（正面/负面）
        super().__init__()
        
        # 1. Embedding层：将token ID转为词向量
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        
        # 2. RNN层：提取序列特征
        self.rnn = nn.RNN(
            input_size=embed_dim,
            hidden_size=hidden_dim,
            num_layers=2,
            batch_first=True,
            dropout=0.5
        )
        
        # 3. Dropout：防止过拟合
        self.dropout = nn.Dropout(keep_prob=0.5)
        
        # 4. Dense层：分类
        self.fc = nn.Dense(hidden_dim, num_classes)
    
    def construct(self, x):
        """
        Args:
            x: token ID序列, shape (batch_size, seq_len)
        Returns:
            logits: 分类logits, shape (batch_size, num_classes)
        """
        # Step 1: Token ID → Embedding
        x = self.embedding(x)  # (B, L, E)
        
        # Step 2: Embedding → RNN特征
        output, hn = self.rnn(x)
        # output: (B, L, H) - 所有时间步的输出
        # hn: (num_layers, B, H) - 最后时间步各层的隐藏状态
        
        # Step 3: 使用最后一层的隐藏状态
        x = hn[-1]  # (B, H)
        
        # Step 4: Dropout
        x = self.dropout(x)
        
        # Step 5: 分类
        logits = self.fc(x)  # (B, num_classes)
        
        return logits

# 使用示例
model = SentimentRNN()

# 输入: batch_size=32, seq_len=50的token ID序
```
