## 一、AI基础知识

### 1.1 深度学习基础概念

#### 1.1.1 神经网络基本组成

- **神经元(Neuron)**: 基本计算单元,包含权重、偏置和激活函数
- **层(Layer)**:
    - 输入层:接收原始数据
    - 隐藏层:特征提取和转换
    - 输出层:产生最终预测结果
- **激活函数**: ReLU、Sigmoid、Tanh、Softmax等

#### 1.1.2 前向传播与反向传播

- **前向传播**: 数据从输入层流向输出层,计算预测值
- **反向传播**: 根据损失函数计算梯度,更新网络参数
- **梯度下降**: 优化算法的核心,包括SGD、Adam、RMSprop等

#### 1.1.3 损失函数

- **分类任务**: 交叉熵损失(CrossEntropy)
- **回归任务**: 均方误差(MSE)、平均绝对误差(MAE)
- **自定义损失**: 根据特定任务设计

### 1.2 MindSpore框架基础

#### 1.2.1 MindSpore特点

- **全场景支持**: 端、边、云统一架构
- **自动并行**: 自动切分模型和数据
- **动静统一**: 支持动态图和静态图
- **AI原生**: 为AI设计的编程范式

#### 1.2.2 MindSpore核心概念

## 三、模型训练与调优

### 3.1 训练流程搭建

#### 3.1.1 数据准备

```python
import mindspore.dataset as ds

# 1. 创建数据集
def create_dataset(data_path, batch_size=32, shuffle=True):
    dataset = ds.MnistDataset(data_path, shuffle=shuffle)
    
    # 数据增强
    dataset = dataset.map(operations=[
        vision.Resize((32, 32)),
        vision.Rescale(1.0/255.0, 0),
        vision.Normalize(mean=[0.1307], std=[0.3081]),
        vision.HWC2CHW()
    ])
    
    # 批处理
    dataset = dataset.batch(batch_size, drop_remainder=True)
    return dataset

train_dataset = create_dataset("./data/train")
```

#### 3.1.2 定义网络模型

```python
class ConvNet(nn.Cell):
    def __init__(self, num_classes=10):
        super(ConvNet, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, 3, pad_mode='pad', padding=1)
        self.conv2 = nn.Conv2d(32, 64, 3, pad_mode='pad', padding=1)
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)
        self.relu = nn.ReLU()
        self.flatten = nn.Flatten()
        self.fc1 = nn.Dense(64 * 8 * 8, 128)
        self.fc2 = nn.Dense(128, num_classes)
    
    def construct(self, x):
        x = self.relu(self.conv1(x))
        x = self.pool(x)
        x = self.relu(self.conv2(x))
        x = self.pool(x)
        x = self.flatten(x)
        x = self.relu(self.fc1(x))
        x = self.fc2(x)
        return x
```

#### 3.1.3 训练配置

```python
# 1. 实例化模型
model = ConvNet(num_classes=10)

# 2. 定义损失函数
loss_fn = nn.CrossEntropyLoss()

# 3. 定义优化器
optimizer = nn.Adam(model.trainable_params(), learning_rate=0.001)

# 4. 定义评估指标
metrics = {'accuracy': nn.Accuracy()}
```

#### 3.1.4 训练执行

```python
from mindspore import Model
from mindspore.train import LossMonitor, TimeMonitor, CheckpointConfig, ModelCheckpoint

# 创建Model对象
model_train = Model(model, loss_fn=loss_fn, optimizer=optimizer, metrics=metrics)

# 配置回调函数
callbacks = [
    LossMonitor(per_print_times=100),
    TimeMonitor(),
    ModelCheckpoint(prefix="model", directory="./checkpoints", 
                   config=CheckpointConfig(save_checkpoint_steps=500))
]

# 执行训练
epochs = 10
model_train.train(epochs, train_dataset, callbacks=callbacks)

# 评估模型
test_dataset = create_dataset("./data/test", shuffle=False)
result = model_train.eval(test_dataset)
print(f"Test Accuracy: {result['accuracy']:.4f}")
```

### 3.2 超参数调优

#### 3.2.1 学习率策略

```python
from mindspore.nn.learning_rate_schedule import ExponentialDecayLR, WarmUpLR, CosineDecayLR

# 1. 指数衰减
lr_schedule = ExponentialDecayLR(learning_rate=0.1, decay_rate=0.9, decay_steps=1000)

# 2. 余弦退火
lr_schedule = CosineDecayLR(min_lr=0.0001, max_lr=0.1, decay_steps=5000)

# 3. 学习率预热
lr_schedule = WarmUpLR(learning_rate=0.1, warmup_steps=1000)

# 应用学习率策略
optimizer = nn.Adam(model.trainable_params(), learning_rate=lr_schedule)
```

#### 3.2.2 批大小(Batch Size)选择

- **小批量(8-32)**: 更好的泛化,但训练慢
- **中批量(64-128)**: 平衡训练速度和性能
- **大批量(256+)**: 训练快,但可能过拟合

#### 3.2.3 正则化技术

```python
# 1. L2正则化(权重衰减)
optimizer = nn.Adam(model.trainable_params(), 
                   learning_rate=0.001,
                   weight_decay=0.0001)

# 2. Dropout
class NetWithDropout(nn.Cell):
    def __init__(self):
        super().__init__()
        self.dropout = nn.Dropout(keep_prob=0.5)
        self.fc = nn.Dense(128, 64)
    
    def construct(self, x):
        x = self.dropout(x)
        return self.fc(x)

# 3. 数据增强
augmentation = [
    vision.RandomHorizontalFlip(prob=0.5),
    vision.RandomRotation(degrees=15),
    vision.RandomColorAdjust(brightness=0.2)
]
```

#### 3.4.2 常见问题诊断

- **损失不下降**: 检查学习率、数据标签、网络结构
- **过拟合**: 增加正则化、数据增强、减少模型复杂度
- **欠拟合**: 增加模型容量、训练更多轮次
- **梯度消失/爆炸**: 使用BatchNorm、残差连接、梯度裁剪
