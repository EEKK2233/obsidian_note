# 题2
-  一台32个处理器的计算机，对远程存储器访问时间为400ns。除了通信以外，假设计算中的访问均命中局部存储器。当发出一个远程请求时，本处理器挂起。处理器时钟为1GHz，如果指令基本的IPC为2(设所有访存均命中Cache)，求在没有远程访问的状态下与有0.2%的指令需要远程访问的状态下，前者比后者快多少?
-  *解*
- 有0.2%远程访问的机器的实际CPI为：
-  CPI＝基本CPI＋远程访问率×远程访问开销
	  ＝1/基本IPC＋0.2%×远程访问开销
-  远程访问开销＝远程访问时间/时钟时间
		     ＝400ns/1ns＝400个时钟
-  CPI＝1/2＋0.2%×400＝1.3
-  因此在没有远程访问的状态下的机器速度是有0.2%远程访问的机器速度的*1.3／0.5＝2.6*倍。
